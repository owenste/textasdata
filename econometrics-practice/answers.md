# 练习 01 参考答案

先自己想，再看答案。下面的数字来自 `data/wdi_panel.csv`（2026 年 10 月下载）。世界银行会修订历史数据，重新下载后数字可能略有变化。

## 第一部分：固定效应

**1.1 系数为什么从 0.88 降到 0.18，再降到 0.05？**

混合 OLS 主要在比较**不同国家**。新加坡、卢森堡这类小国天然更依赖贸易，同时又很富；大国国内市场大，贸易占 GDP 的比重就低。国土面积、地理位置、制度这些因素，同时影响贸易开放度和收入，构成遗漏变量。

加国家固定效应后，只比较**同一个国家内部**随时间的变化，不随时间变化的国家特征都被消掉，系数降到 0.18。

再加年份固定效应，消掉所有国家共同的趋势：1995–2019 年全球贸易占比和收入都在一起上升，这种"同时变大"并不说明二者有因果关系。去掉共同趋势后，系数只剩 0.05。

**1.2 模型 3 能解释成因果吗？不能，原因至少有：**

- **反向因果**：变富了会进口更多，贸易占比也跟着变。
- **随时间变化的混杂因素**：一揽子改革（入世、私有化、汇率改革）往往同时推动开放和增长，固定效应消不掉这类同时发生的变化。
- **机械相关**：贸易开放度的分母就是 GDP，GDP 变动会同时影响等式两边。
- **大宗商品价格**：油价上涨会同时抬高资源出口国的出口和收入。

**1.3 R2 和 Within R2**

R2 很高（0.98），是因为国家固定效应本身就解释了各国收入水平的绝大部分差异：富国一直富，穷国一直穷。

Within R2 只衡量在去掉固定效应之后，贸易开放度能解释多少"国家内部的变化"，这里不到 1%。

R2 高不代表模型好，更不代表识别可信。因果推断关心的是系数有没有偏误，不是拟合度。

## 第二部分：双重差分

**2.1 入盟前两组水平差很多，会破坏 DiD 吗？**

不会。DiD 需要的是**平行趋势**：如果没有入盟，两组出口占比的**变化**会一样，而不是水平一样。水平差异被国家固定效应吸收了。

**2.2 回归和手算为什么一样？**

两种方法都等于 7.88。在平衡面板（每个国家年份都齐全）、只有一个处理时点的情况下，双向固定效应回归的交互项系数在数学上就等于四个均值的 2×2 差分。

回归的好处是能给出（聚类）标准误，能加控制变量，也能扩展成事件研究。

**2.3 入盟前系数接近 0，能证明平行趋势吗？**

不能。平行趋势说的是入盟**之后**、没有入盟时会怎样，这是反事实，永远观察不到。入盟前系数接近 0 只说明"没有发现违反的证据"。

而且这里入盟前的置信区间很宽（大约 ±7 个百分点），即使真有不小的趋势差异，这个检验也很可能查不出来。更严谨的做法是做敏感性分析，看平行趋势被违反到什么程度结论才会翻转，比如 HonestDiD（Rambachan and Roth 2023）。

**2.4 为什么效应 2004 年小、2006–2007 年才变大？**

可能的解释包括：

- 1990 年代签订的《欧洲协定》已经逐步取消了工业品关税，2004 年入盟带来的是单一市场、海关同盟和制度信任，这些作用需要时间。
- 出口能力要靠投资建厂（比如斯洛伐克、捷克的汽车工业），产能形成有滞后。
- 也可能有同期发生的其他因素，DiD 无法和入盟区分开。

**2.5 识别面临的威胁**

- **选择**：入盟不是随机的。要先满足 1993 年确定的哥本哈根标准，能入盟的往往本来就是改革更快、离西欧更近的国家。
- **预期效应**：捷克、爱沙尼亚、匈牙利、波兰、斯洛文尼亚 1998 年开始入盟谈判，拉脱维亚、立陶宛、斯洛伐克 2000 年开始。企业可能提前调整，"前"的时期已经部分受到处理。
- **对照组受到其他冲击**：1998 年俄罗斯金融危机后，卢布和格里夫纳大幅贬值，俄罗斯的出口占 GDP 比重从 1997 年的 25% 跳到 1999 年的 43%，乌克兰从 41% 跳到 54%。这就是对照组曲线 1998–2000 年上升的原因。2000 年代的油价上涨又影响了俄罗斯。
- **战争**：1999 年科索沃战争直接影响了塞尔维亚，北马其顿和阿尔巴尼亚也受到难民潮冲击；波黑处在战后重建期。
- **对照组被"污染"**：克罗地亚 2004 年成为候选国，也可能有自己的预期效应。
- **溢出**：入盟可能让贸易从对照国转向新成员国（贸易转移），这违反了"处理不影响对照组"的假设。

这些问题都需要区域知识才能发现，这正是区域国别学背景在计量研究里的价值。

**2.6 只有 19 个簇**

聚类标准误依赖"簇足够多"的大样本近似。簇少的时候标准误往往偏小，容易过度拒绝原假设，而且这里处理组只有 8 个国家，问题更明显。fixest 默认用自由度为 G−1 的 t 分布来做检验，已经部分修正了这个问题。常见的进一步做法是野聚类自助法（wild cluster bootstrap，Cameron, Gelbach and Miller 2008），或者随机化推断。

## 第三部分：自己动手

**3.1 换结果变量**

```r
did_fdi <- feols(fdi_gdp ~ treated:post | iso3 + year, data = did_data, cluster = ~iso3)
did_gdp <- feols(log_gdppc ~ treated:post | iso3 + year, data = did_data, cluster = ~iso3)
```

| 结果变量 | DiD 估计 | 标准误 | p 值 |
|---|---|---|---|
| FDI 净流入（占 GDP %） | 1.42 | 1.99 | 0.49 |
| 人均 GDP 的对数 | −0.05 | 0.06 | 0.43 |

两个都不显著。

FDI 很"乱"，是因为它被少数大额交易主导：私有化大单、跨国并购，还有经由当地特殊目的实体中转的资本，可以一年冲到 GDP 的几十个百分点，比如匈牙利 2007 年约为 50%。而且 FDI 事件研究里入盟前的系数都在 1.5–2 左右，说明基准年 2003 年本身是处理组的一个低点，基准年选在哪里会影响图的样子。

人均 GDP 不显著不等于入盟对增长没有作用：4 年的入盟后窗口太短，测不出增长效应。

**3.2 稳健性检验**

```r
feols(exports_gdp ~ treated:post | iso3 + year,
      data = did_data %>% filter(!iso3 %in% c("RUS", "UKR", "BLR")), cluster = ~iso3)
```

| 样本 | DiD 估计 | p 值 |
|---|---|---|
| 全部 | 7.88 | 0.026 |
| 去掉 RUS、UKR、BLR | 6.41 | 0.086 |
| 去掉 ALB、MKD、SRB | 10.31 | 0.006 |
| 每次去掉一个对照国 | 7.07 到 8.78 | 都 < 0.05 |

符号和量级比较稳定，但大小取决于对照组怎么选。去掉俄罗斯、乌克兰、白俄罗斯后效应变小：它们在入盟前时期（1998 年危机后）的出口占比被贬值推高了，拉高了对照组"前"的均值。对照组怎么选，本身就是一个需要论证的研究设计决定。

**3.3 安慰剂检验**

```r
placebo <- did_data %>%
  filter(year <= 2003) %>%
  mutate(post = as.integer(year >= 2000))
feols(exports_gdp ~ treated:post | iso3 + year, data = placebo, cluster = ~iso3)
```

结果是 −0.92（标准误 2.73，p = 0.74）。正如预期，在一个没有真正发生处理的年份，没有发现"效应"。这增加了一点可信度，但和 2.3 一样，通过安慰剂检验不等于证明了设计成立。

**3.4 交错 DiD**

```r
stag <- wdi %>%
  filter(iso3 %in% c(treated_countries, control_countries, "BGR", "ROU"),
         year >= 1995, year <= 2010) %>%
  mutate(cohort = case_when(iso3 %in% treated_countries ~ 2004,
                            iso3 %in% c("BGR", "ROU") ~ 2007,
                            TRUE ~ 10000),          # 从未处理的国家，设成一个很大的年份
         treat_post = as.integer(year >= cohort))

feols(exports_gdp ~ treat_post | iso3 + year, data = stag, cluster = ~iso3)
summary(feols(exports_gdp ~ sunab(cohort, year) | iso3 + year,
              data = stag, cluster = ~iso3), agg = "ATT")
```

传统双向固定效应估计是 9.36，Sun-Abraham 估计是 10.59。这里两者差得不多：只有两批处理组，而且有 11 个从未入盟的国家可以做对照。

当处理时间更分散、效应又随时间变化时，传统双向固定效应会拿"已经处理过的国家"当对照，差异可能很大，甚至符号相反。另外注意，这个窗口包含 2008–2009 年金融危机，保加利亚、罗马尼亚入盟后的 4 年几乎都在危机期间。
