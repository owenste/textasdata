## E1 第三轮零结果的等价性检验与最小可检测效应

对第三轮的零结果，用**与第三轮完全相同的模型和样本**，报告：
- 90% 置信区间是否完全落在 ±SESOI 之内（TOST 等价性检验）；
- MDE = 2.8 × SE（80% 功效、5% 双侧）。

| 对象 | 可解释的量 | SESOI（主） | SESOI（敏感性） |
|---|---|---|---|
| B1 南北深度 | f_N(3) = 3α1 + 9α2：从 0 到 3 个南北领域，对年增长率的效应 | ±0.005 | ±0.010 |
| B1 南北 − 南南 | f_N(3) − f_S(3) | ±0.005 | ±0.010 |
| B3a 资本账户逆转 | θ：投资领域从无约束到完全有约束，对逆转概率的效应 | ±0.03 | ±0.06 |
| B3b 关税逆转 | 3φ：从 0 到 3 个领域，对逆转概率的效应 | ±0.03 | ±0.06 |

**SESOI 的理由**：年增长率 0.5 个百分点是政策上显然有意义的差异；逆转概率 3 个百分点约为基准频率（8.5%、10.6%）的三分之一。

**判定**：
- 主 SESOI 下 90% 区间在界内 → 「**等价于 0**」（可以说没有有意义的效应）；
- 只在敏感性 SESOI 下在界内 → 「**只能排除大效应**」；
- 都不在界内 → 「**无法排除有意义的效应**」。
- 两种 FE（年份、区域×年份）分别报告；两者都等价于 0 才称「稳健等价」。

E1 不进入 Holm 家族：它不是新的假设检验，只是对既有区间的解读。

## E2 北方模板的差异：美国 vs 欧盟 vs 其他北方

**构造**：已生效协定版本按成员分为四类，按主设定规则各自取领域并集（0–6）：
- D_US：含美国的协定；
- D_EU：含欧盟 15 国任一成员（且不含美国）的协定；
- D_ON：含其他北方国家（瑞士、挪威、冰岛、加拿大、日本、澳大利亚、新西兰），且不含美国和欧盟成员的协定；
- D_S：不含任何北方国家的协定。

**模型**（核心变量 4 个，线性）：g = a_US·D_US + a_EU·D_EU + a_ON·D_ON + a_S·D_S + CTRL + FE。

**预测**：
- 发展空间派：美国模板对投资、知识产权等领域的约束更强、更可执行（Horn, Mavroidis & Sapir 2010），代价更大 → a_US − a_EU < 0；
- 锁定派：美国模板执行力更强、更可信 → a_US − a_EU > 0。

**检验**：
- **E2a**：a_US − a_EU，双侧 Wald 检验。Holm 调整后 p < 0.05 时，按符号判为支持对应的一派；否则判为「两派都不支持」。
- **E2b**：北方内部异质性，a_US = a_EU = a_ON 的联合 Wald 检验（χ²，2 个自由度）。Holm 调整后 p < 0.05 → 第三轮把北方合并估计**掩盖了异质性**；否则 → 合并估计不构成问题。

**功效说明**：含美国协定的发展中国家只有 16 个，a_US 的估计会很不精确，照实报告 MDE。

## E3 编纂说：深度条款是在确认已有政策，还是在推动新改革？

**编纂说**：发展中国家的深度承诺大多是把已经完成的国内政策写进条约。其可观测含义是：**国内政策的变化发生在承诺之前**。

**以签促改说**：承诺推动国内改革。其可观测含义是：**国内政策的变化发生在承诺之后**。

**设计（领先-滞后对比）**：
Y(t) = λ_F·D_inv(t+2) + λ_L·D_inv(t−1) + L.lny + L.statecap + L.hc + 国家 FE + 年份 FE，国家聚类 SE。
其中 D_inv 为投资领域被有约束力条款覆盖的概率（0–1）。
- 这里有意使用**领先项** D_inv(t+2)（与第二轮 S2 相同的逻辑），这是本检验的设计需要，是「右侧变量滞后一期」规则的**唯一**例外。
- 对比 C = λ_F − λ_L，按「限制越少越自由」的方向解释：

| 结果变量 Y | 编纂说 | 以签促改说 |
|---|---|---|
| **E3a** OECD FDI 限制指数（越高越限制），1997–2020 | C < 0：未来的承诺已伴随当期更低的限制 | C > 0：过去的承诺伴随当期更低的限制 |
| **E3b** KAOPEN（越高越开放），1990–2021 | C > 0 | C < 0 |

**判定**：C 的符号与某一说一致且 Holm 调整后 p < 0.05 → 支持该说；否则 → 无法区分。另外分别报告 λ_F、λ_L 及其 p。
