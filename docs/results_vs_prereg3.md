## 二、逐项结果

### B1 南北 vs 南南（`tab17_north_south.md`）

| | 年份 FE | 区域×年份 FE |
|---|---|---|
| α1 南北深度 | +0.0031（p = 0.411） | −0.0008（p = 0.812） |
| α2 南北深度² | −0.0005（p = 0.473） | +0.0001（p = 0.898） |
| β1 南南深度 | **+0.0147（p = 0.003）** | +0.0046（p = 0.379） |
| β2 南南深度² | **−0.0021（p = 0.003）** | −0.0004（p = 0.567） |

- **两派的预测都不成立，而且方向都相反。** 南北深度与增长之间几乎没有任何关系（一次项、二次项都接近 0）；前两轮看到的曲线形状，**全部来自南南深度**。
- 探索性（未登记）：剔除转型国家后，南南深度的曲线仍在（β2 = −0.0024，p = 0.008），南北深度仍然平坦。所以这一点不是由独联体内部的协定驱动的。
- 局限：发展中国家-年度中南北深度 > 0 的只占 30.8%（南南为 84.9%），南北深度的估计功效较低；两者相关 0.46。

### B2 签署 vs 生效（`tab18_sign_vs_force.md`）

**增长（B2-G）**：已生效领域的系数 γ1 = +0.0162，已签署待生效领域的系数 γ3 = +0.0009（p = 0.643），差值 Δ = +0.0153（原始 p = 0.005，Holm 后 0.029）。
→ 按登记判为「**约束力机制：支持**」，但在区域×年份 FE 下不显著（p = 0.212），所以是**不稳健的支持**。
→ γ3 的 90% 区间 [−0.0023, 0.0041] 超出 ±0.0025，**不能说待生效效应等价于 0**。
→ 需要注意：γ1 就是倒 U 形模型的一次项，它本身在保守设定下就不稳健（第二轮 S6、S7）。所以这一项最准确的表述是：「**在年份 FE 设定下，增长的变化与协定生效同步，而不是与签署同步**」。

**双边出口（B2-B）**：已生效 δ1 = +0.045（p = 0.046），待生效 δ3 = +0.022（p = 0.007），差值 +0.023（p = 0.265）。
→ Holm 校正后差值不显著。按登记的完整规则（待生效系数 > 0 且 p < 0.05、差值 p > 0.10），属于「**信号/预期机制**」：**贸易在协定签署后、生效前就开始增加**，幅度约为生效后的一半。
→ 待生效系数的 p 值不在 Holm 家族之内（登记时它是判定规则的一部分，而不是单独的检验），照实说明。

**两者合起来**：贸易对签署就有反应（预期效应），增长只对生效有反应（在不保守的设定下）。这与「约束力对增长重要」的说法一致，但证据不稳健。

### B3 政策反复（`tab19_policy_reversal.md`）

- 资本账户逆转（基准频率 8.5%）：投资领域约束力的系数 −0.022（p = 0.394），方向与锁定派一致，但不显著。
- 关税逆转（基准频率 10.6%）：+0.006（p = 0.486），方向相反。
- **没有证据表明有约束力的深度降低了政策逆转的概率。** 这是对锁定理论最直接的检验，结果为否定。局限：逆转事件少（约 250 个和 200 个），检验功效有限；关税数据 1990 年代缺失较多。

## 三、对理论的含义

| 命题 | 第三轮证据 | 判断 |
|---|---|---|
| 锁定派：与北方大国签的协定更可信、收益更大 | 南北深度与增长无关；方向相反 | **不支持** |
| 锁定派：约束力降低政策逆转 | 资本账户方向一致但不显著；关税方向相反 | **不支持** |
| 发展空间派：南北深度的代价更大 | 南北深度的曲线是平的 | **不支持** |
| 约束力本身重要（生效 vs 签署） | 增长：生效时才有变化（不稳健）；贸易：签署后就有预期效应 | **弱支持** |

**三轮合起来，最一致的图景是**：

1. IPE 里对立的两派，各自预言的机制（北方锚定带来可信度、北方模板压缩发展空间、承诺锁定政策）**在发展中国家的跨国数据里都检测不到**；
2. 深度与增长之间仅有的规律（弱的收益递减）**只出现在南南协定里**。南南协定多是区域性的，这与第二轮「对区域×年份 FE 敏感」的发现相互印证：规律更可能与区域经济共同体的整体发展有关，而不是与「承诺深度」本身有关；
3. 贸易对协定有反应，而且签署后、生效前就有反应。协定的经济作用更像「协调预期」，而不是「法律锁定」。

建议把论文的核心论点从「承诺校准」进一步调整为：

> **深度贸易协定对发展中国家既不是「锁定改革的锚」，也不是「束缚发展的紧身衣」。** 两派理论预言的机制在跨国数据中都检测不到；深度与增长之间仅有的弱规律集中在南南区域协定中，并且对区域共同冲击敏感。协定的经济作用更多体现为贸易预期的协调，而不是法律约束对国内政策的锁定。

这个论点可以直接回应 RIPE 的核心争论（Wade 2003；Shadlen 2005 对 Büthe & Milner 2008；Baccini & Urpelainen 2014），而且每一步都有事前登记的检验支撑。
