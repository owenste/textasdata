# 事前登记（第六轮）：承诺与约束的分离是否具有系统性（N1–N3）

**登记时间**：2026-09-23，以本文件首次提交的 git 提交时间为准。
**理论**：`docs/cn_paper_theory_core.md`（承诺与约束的分离）。本轮检验其中唯一只有案例证据的推论三，以及推论二。
**原则**：本文件提交之前，没有运行过下文任何一项检验。可行性检查只看了编码含义和样本量，**没有按伙伴类型或领域计算任何分离指标**。

## 可行性检查的全部结果
- **世行 DTA 的编码含义**（「read me」表）：
  - AC：0 = 未提及（或提及过于笼统），1 = 提及；
  - LE：0 = 未提及或无法律约束力，1 = 有约束性语言但被争端解决条款明确排除，2 = 提及且有法律约束力。
  - 所以「AC = 1 且 LE < 2」恰好对应「写进文本但不具完整约束力」，其中 LE = 1 是形式分离中「排除争端解决」的一类。
- **样本**：世行 DTA 398 个协定中，至少有一个发展中国家成员的 347 个：南南 196 个（其中区域多边 49 个），南北 151 个；另有 51 个为北北协定，排除。
- **服务与货物生效日**：同时涉及服务、且两个日期都有记录的，南南 80 个、南北 88 个。

**已看过的数据**：本研究此前只用过 LE = 2 的编码（构造 D）和协定层面的货物生效时间线；AC 编码、LE = 0/1 的区分、货物与服务生效日之差**都没有看过**。第五轮之后做的中国—冰岛、南方共同市场人工核对属于个案，不涉及以下系统比较。

## 共同设定
- **分析单位**：协定 × 领域（六个领域，与主设定相同的条款映射：技术标准 = SPS、TBT；投资 = TRIMs、投资、资本流动；服务 = GATS；政府采购；竞争政策 = 竞争政策、国家援助、国有贸易企业；知识产权 = TRIPs、知识产权）。
- **领域被涉及**：该领域任一条款 AC = 1；**领域有约束力**：该领域任一条款 LE = 2；**形式分离**：被涉及但没有约束力。
- **伙伴类型**：协定成员（世行「Bilateral Information」表）中含任一北方国家（1995 年传统 OECD 高收入 23 国）→ 南北；否则 → 南南。
- **签署时期**：以货物签署日期划为 1995 年以前、1995–2004、2005–2014、2015 年以后四段，用于控制「早期协定措辞更笼统」的时代差异。
- **标准误**：按协定聚类（N1、N3）；异方差稳健（N2，协定层面）。

## 检验

### N1 形式上的分离
- **N1a（伙伴）**：线性概率模型，分离 = β·南南 + 领域 FE + 签署时期 FE，样本为被涉及的协定 × 领域。**预测 β > 0**（南南协定中写进文本但不具约束力的比重更高）。
- **N1b（领域，协定内比较）**：分离 = 领域虚拟变量 + 协定 FE，以技术标准为参照。**预测**：政府采购与竞争政策两项系数的平均值 > 0。

### N2 时间上的分离
- 服务生效滞后 = 服务生效年 − 货物生效年（负值按 0 处理）；样本为涉及服务、两个日期都有记录的协定。
- 模型：滞后 = β·南南 + 签署时期 FE。**预测 β > 0**。
- 另报告南南区域多边协定与南北协定的均值比较（描述性，不进入 Holm 家族，因为样本太小）。

### N3 领域选择
- 在被涉及的协定 × 领域中：有约束力 = 领域虚拟变量 + 协定 FE（协定内比较）。
- **预测**：政府采购的系数减去其余五个领域系数的平均值 < 0；描述性上，政府采购的 LE/AC 比为六个领域中最低。
- 判定需要两者同时成立。

## 判定与多重检验
- **第六族**：N1a、N1b、N2、N3，共 4 项，Holm 校正；方向正确且调整后 p < 0.05 → 支持；方向正确但不显著 → 方向一致；方向相反 → 不支持。
- **框架的修改规则**（事先写定）：
  - N1a 与 N2 都不支持 → 「分离在南南最强」不成立，推论三改写为「分离普遍存在、不因伙伴而异」；
  - N1b 与 N3 都不支持 → 推论二（政府采购分离最强）不成立；
  - 四项都不支持 → 「承诺与约束的分离」作为系统性机制不成立，论文只保留案例层面的表述。

## 不做的事
- 不根据结果修改领域映射、伙伴分类、时期划分或样本；
- 所有结果无论支持与否，一律报告。
