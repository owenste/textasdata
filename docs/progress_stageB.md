## 二、做了什么

1. **EIA 变量（脚本 05）**：Larch 数据库解压后有 23 GB，所以采用流式读取。过程中发现一个陷阱：Larch 在「本国对本国」的行上也把协定变量记为 1。修正后识别出 215 个含 EIA 成分的协定，与官方说明的 218 个吻合 98.6%。
2. **面板（脚本 06）**：严格按原文附录 A1 的变量定义构造。通胀有两种可能的算法（对数差、简单增长率），用 Table 1 的分布判断原文用的是对数差。
3. **样本对齐**：按原文规则，我们的样本有 149 国。其中原文附录 A 的 143 国**全部在内**，另外多出古巴、阿曼、波多黎各、巴勒斯坦、塞尔维亚、南苏丹 6 个，很可能是新版 GMD 补齐了这些国家的数据。只保留原文名单的 143 国后，N 误差从 +7.1% 降到 +4.7%。
4. **估计（脚本 07）**：用 Python 的 linearmodels 实现，对应关系是 reghdfe → PanelOLS 双向 FE + 国家聚类，xtscc → Driscoll-Kraay（Bartlett 核，滞后 3 期）。R² 按原文命令的口径计算：0.21 vs 0.17、0.16 vs 0.13。

## 三、未解决的差异（如实报告）

1. **通胀系数大了约 3 倍。** 这个系数对恶性通胀观测的处理方式极其敏感：用对数差为 −0.027，用简单增长率为 −0.0005，简单增长率再做 99.5% 缩尾为 −0.0067。原文的 −0.0084 落在这个区间之内，但原文没有说明怎么处理极端值，所以无法确定。符号和显著性在所有处理方式下都稳健。
2. **EIA 的分布对不上。** 原文 Table 1 的均值 2.54、最大值 32；我们的在生效数是 1.92/24，累计加入数是 2.48/52。原文 SD 7.86 与 P90 = 9 放在一起也不太协调。可能是 Larch 数据版本不同所致。不过无论用哪种定义，回归系数都不显著。
3. **第(1)列未复刻。** Python 没有 xtdpdbc，我改用半面板刀切法做偏差校正，结果不可靠：前后两半的估计差异很大（例如增长持续性前半段 0.146、后半段 0.076），说明 65 年间增长动态本身发生了变化，违背了刀切法「前后参数相同」的前提。结果是收敛项被「校正」到接近 0，与原文不符。要完成 A 级复刻，需要在 Stata 里运行 `xtdpdbc`。
4. **数据版本。** 原文用的是 GMD 2025 版，官网现在只能下载 2026_06 版；委内瑞拉早期的 GDP 水平值也有拼接问题（不影响回归）。
