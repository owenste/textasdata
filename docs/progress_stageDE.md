## 二、阶段 D：主回归（`tab02_main.md`、`fig02_marginal.png`、`tab03_heterogeneity.md`、`fig03_quantile.png`）

**D1 增量测试**：每组内各列用同一样本，所以 AIC/BIC 可比。
- A 组（C 可得样本，1,514 个观测）：加入 D、C、D×C 后 AIC、BIC 都没有改善，基准模型最优。
- B 组（P 可得样本，452 个观测）：加入 D 后 AIC 仅改善 0.6（< 2，视为无差别）；D 本身在该样本中显著为正（0.0103，p < 0.10）。

**D2 边际效应图**：在 C 的全部取值范围内，D 对增长的边际效应和对 KAOPEN 的边际效应都不显著，所以图 2 看不到「C 越高、D 越有效」的形态。

**D3 异质性**：
- **GFC 前后**：危机前 D 的系数为 +0.0047，危机后为 −0.0107，差异在 10% 水平显著（−0.0082）。危机后，深度与增长的关联变弱。
- **大宗商品依赖**：非依赖国 D 为 +0.0057（p < 0.10），依赖国约为 0，组间差异不显著。
- **C 高/低**：两组都不显著。

**D4 MM-QR 分位数回归**：9 个分位上 D 和 D×C 都不显著。D 的系数从低分位的 0.0006 升到高分位的 0.0081，但置信区间始终包含 0。

**D5 门限**：
- 以 C 为门限变量：不存在门限（p = 0.59）。
- **以 D 为门限变量：γ = 2.52，p = 0.010**。低于门限时 D 的系数为 +0.0157，高于门限时为 −0.0098。约 32% 的发展中国家-年度处在门限以下。

## 三、阶段 E：稳健性（`tab04_robustness.md`、`tab05_system_gmm.md`）

- **E1 剔除中国**：全部结论不变。
- **E2 子指标替换**（D 三种、C 两种、P 三种、S 一种）：H2 始终不显著；H4 只在换成 S_sd 时失去显著性；H3 只在 C 换成 BTI 时显著。
- **其他变体**：剔除 DB 数据违规 4 国、Driscoll-Kraay 标准误、全样本、与 EIA 协定数赛马、不控制国家能力，结论均不变。
- **E3 系统 GMM**（Blundell-Bond，两步法，collapse 工具）：
  - H1 设定：D ≈ 0（p = 0.96），AR(2) 通过，Hansen p = 0.063（边缘）。
  - H2 设定：Hansen p = 0.000，工具无效，不可信。
  - pydynpd 已用模拟数据验证能估出已知参数。
- **补充检验**：D 的二次项在三种口径下都显著为负，与门限结果一致。

## 四、方法说明与局限

1. 所有系数都是条件效应（研究计划第 6 节），GMM 也不宣称因果。
2. H2 的样本只有 2007–2020 年，每国约 13 年，属于短面板：滞后增长的系数受 Nickell 偏差影响，出现负值。
3. **倒 U 形是探索性发现**（门限搜索本身就是探索），需要在新时期或新样本上验证；不能当作事先预测的证实。
4. 数据替代与缺口：PWT 人力资本按其公式重算；GeoC/GeoV 未构造；FKRSU、ISO Survey 需手动下载；Y1 只覆盖投资/资本领域。
5. 为拿到可复现的结果，所有随机过程（自助法）都固定了随机种子（20260923）。
