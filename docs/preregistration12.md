# 事前登记（第十二轮）：开放条件下的增长联动——在原作者增长方程中的检验

**登记时间**：2026-09-25，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有构造过贸易伙伴增长变量，也没有估计过下文任何模型。

**此前看过什么（如实披露）**：
- 第八轮在同一方程、同一样本上估计过投资与各类地缘、深度变量的交互，都不显著；
- 各国自身增长率在前几轮反复用作结果变量；
- **伙伴增长 g^P、南方与北方伙伴的分解、中国增长 × 对华依存度，此前从未构造或估计过。**

## 一、问题与理论对照

徐秀军关于现代化「关系转向」的论述中，「联动发展」是可以检验的现实命题：开放条件下，各国现代化相互依存、相互带动。本轮把它拆成五个命题。每个命题都对照一个竞争性理论的预测：

| 编号 | 命题 | 关系性认知的预测 | 对照理论的预测 |
|---|---|---|---|
| L1 | 联动存在 | 伙伴增长带动本国增长 | 经典现代化理论：控制自身条件后无关 |
| L2 | 开放是连接机制 | 开放度越高，联动越强 | 若只是共同冲击，则与开放度无关 |
| L3 | 联动增强 | 2001 年以后的联动弹性大于 1991–2000 年 | 不变 |
| L4 | 南南联动 | 南方伙伴的增长带动本国增长 | 依附论、世界体系论：带动主要来自中心国家 |
| L5 | 中国的带动 | 对华出口依存度越高，中国增长的带动越强 | —— |

## 二、共同设定（与第八轮相同的原作者方程 1）

g_it = φ·g_i,t−1 + ρ·ln y_i,t−1 + β·X_i,t−1 + [联动项] + μ_i + τ_t + ε_it

- X：投资率、ln 人口、人口增长率、通胀、协定数量（EIA 累计），全部滞后一期；
- 样本：发展中国家，1991–2023 年；
- 国家 FE + 年份 FE，国家聚类；
- **区域×年份 FE 版本并排报告**。它会吸收区域内的共同冲击，是更严格的检验。

## 三、变量

- **伙伴权重** w_ijt：i 对 j 的出口占 i 对全部有增长数据伙伴出口的份额，取 t−3 至 t−1 年的平均（前定权重）。1991–1993 年用 1990 年起可得的年份。数据为 IMTS 发展中国家报告的出口。
- **伙伴增长** g^P_it = Σ_j w_ijt · g_jt。g_jt 为伙伴 j 当年的实际 GDP 对数增长（GMD，2023 年以前）。
- **北方与南方分解**：g^N = Σ_{j∈北方} w_ijt·g_jt，g^S = Σ_{j∉北方} w_ijt·g_jt，所以 g^P = g^N + g^S。
  - 北方为本研究的 23 国（`depth_tools.NORTH`）；
  - 中国计入南方。
- **开放度** open_i,t−1 = 出口占 GDP 比重 + 进口占 GDP 比重（GMD），滞后一期，在估计样本内标准化。
- **对华依存度** s^CN_it：i 对华出口份额，t−3 至 t−1 年平均。
- **不含中国的伙伴增长** g^P,−CN：从 g^P 中去掉中国一项，不重新归一。

## 四、检验（第十二族，Holm 校正）

| 编号 | 模型加入 | 统计量 | 预测 |
|---|---|---|---|
| **L1** | g^P | θ | > 0 |
| **L2** | g^P、z(open)、g^P × z(open) | 交互项 | > 0 |
| **L3** | g^P × 1{t ≤ 2000}、g^P × 1{t ≥ 2001} | 后期 − 前期 | > 0 |
| **L4** | g^S、g^N | θ_S | > 0 |
| **L5** | g^P,−CN、s^CN、s^CN × g_CN,t | 交互项 | > 0 |

- g_CN,t 只随年份变化，被年份 FE 吸收，所以模型中只放交互项和 s^CN。
- **辅助项**（不参与判定）：L4 中 θ_S − θ_N 及其 90% 区间。

**判定**：
- 方向正确，且 Holm 调整后 p < 0.05 → **支持**；
- 在此基础上，如果区域×年份 FE 版本也方向相同、原始 p < 0.05 → **稳健支持**；
- 方向相反，且调整后 p < 0.05 → **证伪**；
- 其余 → **不显著**。

**L1 的额外条件：置换检验**
- 做法：对每个国家，把它的伙伴权重随机分配给其他伙伴（每国一个固定的随机置换，各年共用），重新计算 g^P 并估计 θ。共 200 次，种子 20260925。
- 条件：L1 要判为支持，真实的 θ 必须高于置换分布的第 95 百分位。
- 目的：排除「任何一个增长加权平均都会显著」的可能，也就是纯共同冲击。

## 五、稳健性（只报告，不改变判定）

1. 固定基期权重（1990–1994 年平均）；
2. 用进出口合计作为权重；
3. 伙伴增长滞后一期 g^P_{t−1}；
4. 剔除 2009 年和 2020 年（全球性衰退年份）；
5. 从样本中剔除中国；
6. L1 剔除同区域伙伴，只用区域外伙伴的增长，以减轻区域共同冲击。

## 六、不做的事

- 不根据结果修改权重、时期划分、北方定义或样本；
- 其他分析一律标注为探索性；
- 所有结果无论支持与否，一律报告。
