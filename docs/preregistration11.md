## 一、问题

地缘政治风险上升以后，贸易协定的约束性规则对贸易的促进作用是否减弱？

**理论依据**：
- 约束性规则主要降低**商业政策风险**，例如关税反复、歧视性规制；
- 以安全为由的贸易限制通常落入协定的**安全例外**，不受规则约束；
- 因此，当贸易面临的主要风险从前者转向后者时，规则的边际作用可能下降，而且这种下降在政治立场差异大的国家对之间应当更明显。

**两种结果都有意义**：
- 效应减弱：说明制度型开放需要与安全层面的合作相配合；
- 效应不减弱：说明规则红利具有韧性。

## 二、数据与样本

- **结果变量**：120 个发展中国家对全部伙伴的出口（IMF IMTS，美元），与第二轮 P6 相同。
- **时期**：1991–2023 年。
- **深度**：L_Dij = D_ij(t−1)，国家对层面约束性深度（0–6），与第二轮相同（`data/clean/Dij_dyad_year.csv`）。
- **阵营**：
  - p 为联合国投票位置（以中美为两极），取 1990–2023 年的平均值；
  - p > 1/3 为 W 侧，其余为 C 侧；
  - **XS_ij** = 1：两国分处两侧；
  - 没有理想点的经济体剔除。
- **POST_t** = 1{t ≥ 2017}。

## 三、模型

PPML（pyfixest `fepois`），出口方×年、进口方×年、国家对 FE，按无方向国家对聚类。

- **模型 A**：X_ijt ~ L_D×PRE + L_D×POST
  - PRE = 1 − POST；
  - 两个系数分别是两个时期的深度效应。
- **模型 B**：在模型 A 基础上，按 XS 分组，得到四个系数：
  - L_D×PRE×(1−XS)、L_D×POST×(1−XS)；
  - L_D×PRE×XS、L_D×POST×XS。

## 四、检验（第十一族，Holm 校正）

| 编号 | 假设 | 统计量 | 预测 |
|---|---|---|---|
| **T0** 基准 | 地缘政治风险上升之前，深度促进贸易 | 模型 A：β_PRE | > 0 |
| **T1** 时代减弱 | 2017 年以后，深度效应减弱 | 模型 A：β_POST − β_PRE | < 0 |
| **T2** 阵营差异 | 减弱在跨阵营国家对中更明显 | 模型 B：(β_POST,XS − β_PRE,XS) − (β_POST,同侧 − β_PRE,同侧) | < 0 |

**判定**：
- 方向正确且 Holm 调整后 p < 0.05 → **支持**；但 T1、T2 还要通过第五节的前趋势条件；
- 方向相反且调整后 p < 0.05 → **证伪**（T1 证伪即「规则红利具有韧性，甚至增强」）；
- 其余 → **不显著**。

## 五、前趋势条件（T1、T2）

需要排除一种可能：深度效应在 2017 年之前就在持续下降。

- **T1**：在模型 A 中加入 L_D × PRE × (年份 − 2016)，即 2017 年前深度效应的线性趋势。
  - 若该趋势项为负且 p < 0.10，T1 即使显著，也只能判为「存在前趋势，不能解释为 2017 年以后的转折」。
- **T2**：在模型 B 中对跨侧、同侧分别加入同样的趋势项，检验两者之差。规则相同。
- 另外报告按五年分段的深度系数（1991–95、…、2016–20、2021–23），只作描述。
