## 一、共同设定（按原作者的方程 1）

g_it = φ·g_i,t−1 + ρ·ln y_i,t−1 + β·X_i,t−1 + μ_i + τ_t + ε_it

- X：投资率、ln 人口、人口增长率、通胀、协定数量（EIA 累计），全部滞后一期；结果为实际 GDP 增长率。
- 样本：本研究的发展中国家（与地缘变量的覆盖一致，约 120 国），1991–2023 年。**与原作者的偏离**：原作者用的是人口 200 万以上的全部经济体、1960–2024 年。这里只能复制其设定的方式，不能复制其样本。
- 交互项中的调节变量在估计样本内标准化；投资率保持原单位。
- 国家聚类标准误。**区域×年份 FE 版本并排报告**；两者都成立才称「稳健支持」。

## 二、检验

| 编号 | 假设 | 模型中加入 | 预测 |
|---|---|---|---|
| **R1** 复制原作者 | 连接度放大投资回报 | L.GeoC、L.投资 × L.GeoC | 交互 > 0 |
| **R2** 复制原作者（国家能力） | 国家能力放大投资回报 | L.国家能力、L.投资 × L.国家能力，**限 2016 年以前**（避开沿用值） | 交互 > 0 |
| **A1** 双循环「相互促进」（平衡） | 跨阵营平衡放大国内投资的回报 | L.CONN、L.投资 × L.CONN | 交互 > 0 |
| **A2** 双循环「相互促进」（桥接） | 桥接位置放大国内投资的回报 | L.BRIDGE、L.投资 × L.BRIDGE | 交互 > 0 |
| **B** 碎片化 | 2018 年以后，跨阵营平衡的放大作用更强 | A1 的模型 + L.CONN × 2018 后、L.投资 × 2018 后、L.投资 × L.CONN × 2018 后 | 三重交互 > 0 |
| **C** 制度型开放是投资的互补品 | 约束性规则提高投资效率 | L.D（核对修正口径 V2）、L.投资 × L.D | 交互 > 0 |
| **D** 碎片化下的脆弱性 | 2018 年以后，地缘脆弱性的代价更大 | L.GeoV_F、L.GeoV_F × 2018 后 | 交互 < 0 |

「2018 后」= 1{年份 ≥ 2019}：变量滞后一期，所以 2018 年的暴露影响 2019 年的增长。

**多重检验**：第八族为 R1、R2、A1、A2、B、C、D 共 7 项，Holm 校正；方向正确且调整后 p < 0.05 → 支持。

## 三、新旧变量的比较：样本外预测力

- **训练期** 1991–2015，**检验期** 2016–2023。
- 在训练期估计国家与年份 FE 模型；检验期的预测 = 系数 × 解释变量 + 国家效应。检验期的年份效应未知，所以预测误差在每年内去均值之后再计算均方根误差（RMSE），只比较国家之间的相对预测能力。
- 比较三个模型：
  1. 基准（方程 1）；
  2. 基准 + 原变量（GeoC、投资 × GeoC、GeoV）；
  3. 基准 + 新变量（CONN、BRIDGE、投资 × CONN、投资 × BRIDGE、GeoV_F）。
- **判定**：新变量模型的样本外 RMSE 低于原变量模型 → 新变量「预测力更强」；两者都不低于基准 → 地缘变量在样本外都没有增益。
- 另外用整群自助法（按国家，499 次，种子 20260923）给出 RMSE 差值的区间，仅作参考。
