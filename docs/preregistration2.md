## 第一类：增强检验

### S1 安慰剂：签署了但从未生效的协定

- **构造**：从未生效（DESTA 中无生效年份）且有内容编码的母协定，按主设定 D 的同一规则（DESTA 条款 × 校准的约束力概率，领域并集）构造「安慰剂深度」D_pl，自签署年起计入。
- **模型**：基准二次模型中加入 L.D_pl 与 L.D_pl²。
- **判定**：「安慰剂干净」= L.D_pl 与 L.D_pl² 的联合检验 p > 0.10，**且**主设定 D² 仍 < 0、p < 0.05。
- **逻辑**：如果「签了但没生效」也伴随同样的增长模式，说明起作用的是签约背后的其他因素，而不是承诺的约束力。

### S2 前导项检验（反向因果的另一种检验）

- 基准二次模型中加入 D(t+2) 与 D(t+2)²。
- **判定**：两个前导项的联合检验 p > 0.10 = 通过。

### S3 零结果的等价性检验（TOST）

- **对象**：H2（D×C）、P2（γ3）、P3（S×c），因变量为增长；Y1（D_投资 × C），因变量为 KAOPEN。
- **最小有意义效应（SESOI）**：增长模型 ±0.0025（即 0.25 个百分点/标准差）；KAOPEN 模型 ±0.02。敏感性：增长模型 ±0.005。
- **判定**：90% 置信区间完全落在 ±SESOI 之内 = 「等价于 0」（可以正面说「没有有意义的效应」）；否则只能说「不显著，但不能排除有意义的效应」。

### S4 最小可检测效应（MDE）

对 S3 中的每个系数，以及 D²、P1 导数，报告 MDE = 2.8 × SE（80% 功效，5% 双侧）。

### S5 多重检验校正（Holm）

- **第一族**：P1（主检验，自助法双侧 p = 2 × min(自助分布中 ≤ 0 的比例, ≥ 0 的比例)）、P2、P3。
- **第二族**：P5、P6、P7a、P7b、P8。
- 报告原始 p 与 Holm 调整后的 p；**判定以调整后的 p 为准**。

### S6 以「区域 × 年份」固定效应为保守主设定

用区域 × 年份 FE 替代年份 FE，重估：
- 倒 U 形基准；
- P1 主检验（整群自助法 499 次）；
- H4（S_jump）。

判定规则分别同原登记。今后论文中以此为保守主设定并排报告。

### S7 设定曲线（倒 U 形的 D²）

五个维度的全部组合，共 4 × 3 × 2 × 3 × 2 = 144 个设定：

| 维度 | 选项 |
|---|---|
| D 的口径 | D、D_strict、D_loose、D_wbonly |
| 控制变量 | Aizenman 六项；+国家能力、人力资本；+国家能力、人力资本、GeoV、GeoC |
| 固定效应 | 年份；区域 × 年份 |
| 样本 | 发展中国家；剔除中东欧入盟国；全部国家 |
| 时期 | 1990–2023；1995–2019 |

**判定**：D² < 0 且 p < 0.05 的设定占比 ≥ 2/3 → 稳健；< 1/3 → 脆弱；其余 → 中等。

## 第二类：新预测（第二族，Holm 校正）

### P5 机制：外资流入的倒 U 形

- **结果变量**：外资净流入占 GDP 比重（WDI BX.KLT.DINV.WD.GD.ZS），在发展中国家样本的第 1、99 百分位缩尾。
- **模型**：FDI(t) = β1·D(t−1) + β2·D(t−1)² + CTRL + 双向 FE。
- **预测**：β2 < 0（可信度机制：早期承诺吸引外资，之后边际递减）。
- **判定**：β2 < 0 且 Holm 调整后 p < 0.05 → 支持。

### P6 双边引力模型：国家对层面的倒 U 形

- **结果变量**：i 对 j 的出口（IMF IMTS，美元），出口方为 120 个发展中国家。
- **国家对深度 D_ij**：覆盖该国家对的全部生效协定，按主设定规则（世行约束力编码优先，DESTA 校准概率补充）取领域并集，0–6。
- **模型**：PPML，出口方 × 年份、进口方 × 年份、国家对三组固定效应；解释变量 D_ij(t−1)、D_ij(t−1)²；按国家对聚类。
- **预测**：D² < 0。
- **判定**：D² < 0 且 Holm 调整后 p < 0.05 → 支持。

### P7 现代双重差分（Gardner 2022 两阶段 DiD，did2s）

- **P7a**：处理 = 某国 D 首次 ≥ 1（进入有约束力的承诺）。预测：事件后 0–5 年平均效应 > 0。
- **P7b**：处理 = 某国 D 首次 > 3.5（越过拐点）。预测：事件后 0–5 年平均效应 < 0。
- **共同设定**：结果为增长率，发展中国家，1990–2023；以从未处理和尚未处理的国家为对照；事件窗口 −5 至 +5；不加协变量（did2s 的标准用法）。
- **判定**：方向正确且 Holm 调整后 p < 0.05 → 支持；方向正确但不显著 → 方向一致。

### P8 合成控制：墨西哥与波兰

- **处理**：墨西哥 1994 年（D 从 2 跃升到 6，国家能力 0.70，偏低）；波兰 1994 年（D 从 0 升到 4.5，1995 年达 5.3，国家能力 1.45，偏高）。
- **结果变量**：ln(实际人均 GDP，不变价美元) − 其 1993 年值，即以 1993 年为基期的累计增长路径。
- **对照组**：2004 年以前 D 始终 ≤ 1、且 1980–2004 年数据完整的发展中国家。
- **匹配**：1980–1993 年逐年的结果变量。
- **推断**：空间安慰剂；p = 处理国「事后/事前 RMSPE 比」在全部国家中的排名 ÷ (对照国数 + 1)。
- **预测**（来自 P1：能力越低，越早越过拐点）：墨西哥 1994–2004 年平均差距 < 0；波兰差距 ≥ 0。
- **判定**：墨西哥差距 < 0 且 p ≤ 0.10 → 支持；波兰差距 ≥ 0 → 与预测一致。
