## 二、逐项结果

### E1：第三轮的零结果大多「没有信息量」（`tab20_equivalence_round3.md`）

这是本轮最重要、也最令人清醒的结果。

- **南北深度**：从 0 到 3 个南北领域，对年增长率效应的 90% 区间是 [−0.5, +1.5] 个百分点，最小可检测效应为 1.7 个百分点。也就是说，**即使南北深度真的让年增长率提高或降低 1 个百分点（这在政策上是巨大的效应），当前数据也检测不出来**。
- **政策逆转**：最小可检测效应约为 7 个百分点，接近基准频率（8.5%、10.6%）。数据只能发现「逆转几乎全部消失」这种极端效应。
- **南北与南南的差异**：年份 FE 下 90% 区间 [−4.0, −0.1] 个百分点，不含 0（相当于双侧 p ≈ 0.08），方向是南北深度的效应**小于**南南深度。

**含义**：第三轮「锁定派和发展空间派的预测都不成立」这句话，必须改为「**当前数据无力检验两派的预测**」。「既非锚，亦非紧身衣」不能作为**正面结论**，只能作为「**两派的主张都缺乏经验支撑**」这一较弱的表述。

### E2：北方模板确实不同，但只在不保守的设定下（`tab21_north_templates.md`）

| | 年份 FE | 区域×年份 FE |
|---|---|---|
| a_US 美国 | **−0.0028（p = 0.004）** | +0.0006（p = 0.620） |
| a_EU 欧盟 | −0.0009（p = 0.360） | −0.0004（p = 0.760） |
| a_ON 其他北方 | **+0.0026（p = 0.036）** | +0.0009（p = 0.478） |
| a_S 南南 | +0.0019（p = 0.209） | +0.0014（p = 0.465） |

- 年份 FE 下，北方内部**显著异质**（Holm 后 p = 0.038）：与美国签的协定每多一个有约束力的领域，伴随年增长低 0.28 个百分点；与其他北方国家（加拿大、日本、澳大利亚、瑞士等）签的，伴随高 0.26 个百分点；欧盟接近 0。第三轮把它们合并后「与增长无关」，**部分是正负抵消的结果**。
- 美国与欧盟之间的差异不显著（Holm p = 0.64），所以不能据此支持任何一派。
- **区域×年份 FE 下全部消失**。与美国签约的发展中国家主要在拉美（墨西哥、中美洲、智利、秘鲁、哥伦比亚），美国协定的负系数很可能反映了拉美地区的共同经济走势。
- 功效：只有 16 个发展中国家与美国签有协定，美国系数的精确度有限。

### E3：编纂说与以签促改说无法区分（`tab22_codification.md`）

- FDI 限制指数：领先项与滞后项的系数都接近 0，差值 C = +0.004（p = 0.81）。
- KAOPEN：C = −0.058（p = 0.28），符号偏向「以签促改」，但不显著。
- 投资领域的有约束力承诺，与承诺前后的 FDI 限制和资本账户开放**都没有可检测的关系**。这本身与「编纂说」和「以签促改」都不太相符；更符合「**承诺与国内投资政策基本脱钩**」的描述。但由于 FDI 限制指数只覆盖 53 国、700 个观测，功效同样有限。
- 注意：区域×年份 FE 下，领先项对 FDI 限制指数的系数为 +0.071（p = 0.013），即未来的承诺伴随**更高**的当期限制。这与两说都不一致，属于未经 Holm 的次要设定结果，照实列出，不作解读。

## 三、四轮检验合起来，现在能说什么

| 层级 | 结论 | 证据强度 |
|---|---|---|
| 描述性事实 | 发展中国家面对的有约束力深度主要来自南南协定（均值 3.2 对 1.4） | **强**（不依赖统计推断） |
| 替代解释排除 | 签而未生效的协定与增长无关；未来深度不预测当期增长 | 中（功效有限） |
| 形状 | 深度与增长的二次项在 96% 的设定中为负，但显著的只有 24% | **脆弱** |
| 机制：锁定、发展空间、编纂 | 全部检测不到；**且等价性检验显示数据无力排除有意义的效应** | **不确定**（不是「否定」） |
| 北方模板异质 | 美国负、其他北方正，合并时抵消；只在年份 FE 下成立 | 弱 |
| 时间 | 贸易在签署后即有反应；增长与生效同步（不稳健） | 弱到中 |

**最诚实的总结**：
> 在 1990–2023 年发展中国家的跨国数据中，深度贸易协定的增长效应及其机制（锁定、发展空间、编纂）**无法被可靠地识别**。标准设定下看到的规律，在区域共同冲击和样本时期的检验下大多不稳健；而机制检验的最小可检测效应远大于政策上有意义的效应。

这对论文意味着：**本研究最站得住的贡献，是「我们实际上知道得多么少」，以及「为什么知道得这么少」**：深度协定按区域成群出现，跨国面板难以把深度与区域共同冲击分开；机制变量的数据覆盖太窄。这是一篇「可信度评估」论文，而不是「理论验证」论文。
