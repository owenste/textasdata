## 二、H3：登记判定为「支持」，但探索性核查表明是既有趋势

**登记的缺陷（如实说明）**：登记只为 H1 设了前趋势条件，没有为 H3 设。按登记规则 H3 判为「支持」，但以下核查表明，它不能被解释为 RCEP 的效应。

| 核查（探索性） | 结果 |
|---|---|
| **X1 安慰剂**：只用 2017–2021 年，假设 2020-01 生效 | 交互项已经是 −0.039（p < 0.001）：**RCEP 之前就存在同方向的差异** |
| **X6 交互事件研究**（按相对年份，基期 −2 年） | 交互项从 −5 年的 +0.057 平稳下降到 +3 年的 −0.068，**生效时点没有断点** |
| X5 原有深度最浅的成员对 | 几乎全是**中国—东盟**国家对（中国—文莱、柬埔寨、菲律宾、马来西亚、印尼、泰国、越南，D2021 = 0） |
| X3 按深度三分位 | 最浅 +0.038、中间 −0.065、最深 −0.038，都不显著，也不单调 |
| X4 替换数据或样本 | 剔除中澳、剔除东盟内部、镜像数据、延长样本，交互项都在 −0.062 至 −0.070 |

**解读**：H3 反映的是**中国—东盟贸易在 2017–2025 年间持续相对上升**的长期趋势。在原有深度这个变量上，这类国家对恰好处在最浅的一端（中国—东盟自贸协定的约束性条款在世行编码中几乎都是 0）。这不是 RCEP 引起的。

## 三、H4：跨侧差异在生效后才出现（探索性）

| 项目 | 估计（SE） | p |
|---|---|---|
| 登记 H4：跨侧成员对 β + 交互 | −0.072（0.033） | 0.030（Holm 0.091） |
| 辅助：同侧成员对的 RCEP 系数 | +0.033（0.041） | 0.419 |
| 辅助：跨侧 − 同侧 | −0.105（0.033） | 0.001 |
| **X7 安慰剂**（2017–2021，假设 2020-01）：跨侧 − 同侧 | −0.012（0.025） | 0.632 |
| X2 与 H3 同时放入：跨侧交互 | −0.065（0.037） | 0.077 |

**说明**：
- 跨侧（中国一侧 ↔ 日、韩、澳、新）与同侧成员对之间的差距，**在 2020–2021 年的安慰剂期不存在，2022 年以后才出现**。这与 H3 不同，不是既有趋势。
- 但它**不能归因于 RCEP**。2022 年以后同时发生了日韩对华出口管制、半导体限制等国家对层面的地缘冲击。「跨侧 × 2022 年后」在成员对内部与这些冲击完全重合。
- 按登记，H4 是「不显著」。「跨侧 − 同侧 = −0.105」是辅助系数，不是登记的检验，不能作为发现报告。

## 四、这一轮说明了什么

1. **RCEP 的规则层在四年内没有带来可测的贸易增量**。
   - 结论稳健：事件研究干净，七项稳健性检验的方向一致。
   - 这与政策话语中「RCEP 显著扩大区域贸易」的说法不一致，至少在国家对层面、生效后四年内是这样。
2. **区域贸易的重组沿着政治位置展开，而不是沿着协定规则展开**。这来自探索性结果，是描述性的：
   - 中国—东盟贸易持续相对上升（第二节）；
   - 跨侧成员对在 2022 年以后相对下降（第三节）；
   - 与第七轮的发现一致：中国的跨阵营平衡度下降，越南等连接者上升。
3. **对「制度型开放」的含义**：同一个协定框架之内，贸易仍然按地缘位置分化；规则层的统一没有阻止这种分化。
   - 这是一个可以被检验的理论命题：**制度型开放的效果以地缘政治条件为前提**。
   - 本轮只提供了线索，不是检验。

## 五、偏离登记与实施细节

1. **样本规模**：登记的样本规则（≥ 100 个月有记录）选出了 203 个经济体。IMTS 为部分不报告的经济体提供了基于伙伴数据的估计值，所以覆盖面比「实际报告方」更大。规则照登记执行，没有调整。
2. **年度稳健性（第 3 项）的处理年份**：登记没有写明。实际做法是：生效满一个完整日历年的首个年份记为处理年，1 月生效的记为当年。
3. **代码重构**：首次运行后，数据构造部分抽成 `code/rcep_data.py`，供脚本 45、46 共用。重构后重跑脚本 45，结果完全一致。
4. **内存**：X6 按季度分组超出内存，改为按年分组。这是探索性分析，不涉及登记检验。
