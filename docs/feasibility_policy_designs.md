# 可行性调查：转向「政策真正变化的地方」（只查数据，未跑分析）

调查日期：2026-09-24。本文件只记录数据能否取得，不含任何估计结果。

## 一、自贸试验区（FTZ）交错设立

**处理时间（批次）**：
- 上海：2013 年；
- 广东、天津、福建：2015 年；
- 辽宁、浙江、河南、湖北、重庆、四川、陕西：2017 年；
- 海南：2018 年；
- 山东、江苏、广西、河北、云南、黑龙江：2019 年；
- 北京、湖南、安徽：2020 年；
- 新疆：2023 年；
- 内蒙古：2026 年（据中文维基百科，需核实）。

具体日期需按国务院印发总体方案的文件逐一核对。

**数据可得性**：

| 来源 | 结果 |
|---|---|
| 国家统计局数据库 API（data.stats.gov.cn） | 403，被防火墙拦截 |
| 统计年鉴网页（stats.gov.cn/sj/ndsj） | 可访问，但表格只提供 JPG 图片，没有 xls |
| 商务部数据中心 | 响应为空 |
| GitHub 公开省级面板（KarlHeinrich-jpg，2000–2022） | 可下载：30 省（缺西藏），690 行，有 GDP、进出口、二产比重、技术市场成交额、能耗、CO₂；**没有外资** |
| 地级市面板（中国城市统计年鉴） | 云端取不到；用户本人如有 CNKI、CSMAR、EPS 权限可以提供 |

**设计上的问题**：
1. 省级只有 31 个单位，22 个受处理；从未处理的只剩山西、吉林、江西、贵州、西藏、甘肃、青海、宁夏约 8 个，都是中西部，与处理组不可比。交错 DiD 的检验力和平行趋势都难以成立。
2. 自贸试验区只覆盖城市里的一小片，省级、甚至市级结果都被大幅稀释。
3. 文献已经饱和：地级市多期 DiD 研究 FTZ 对外资、创新、碳排放、数字经济等的论文有数百篇。IPE 角度的新意不在这里。

## 二、RCEP / CPTPP 分批生效

- **IMF IMTS**：年度数据已在本地（1990–2025）；**月度查询已确认可用**（`.M` 频率，同一接口）。
- **RCEP 分批生效**：2022-01（10 国）、2022-02（韩国）、2022-03（马来西亚）、2023-01（印尼）、2023-06（菲律宾），天然形成交错处理。
- 本研究已有的协定深度 D、领域编码和地缘位置变量可以直接对接。

**结论**：从数据上看，RCEP 方向可以在云端独立完成；FTZ 方向需要用户提供地级市数据，而且新意有限。
