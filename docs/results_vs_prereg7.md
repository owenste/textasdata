## 一、四项效度标准全部通过

| 标准 | 结果 | 通过 |
|---|---|---|
| **C1 认出连接者** | 越南、墨西哥、波兰在 CONN 或 BRIDGE 中的最佳百分位分别为 0.85、**0.96**、0.85；三国平均 0.89，原 GeoC 为 0.59 | ✓ |
| **C2 不随本国立场漂移** | GeoV_F 与本国立场极端程度的相关为 0.35，原 GeoV 为 0.44 | ✓（改善有限，见下） |
| **C2b 中国 2015 → 2023** | GeoV_F 0.44 → 0.40，与「固定立场」分解的结论一致 | ✓ |
| **C3 俄罗斯 2021 → 2023** | CONN 0.34 → 0.23；中国一侧的贸易份额 0.41 → 0.64 | ✓ |

**墨西哥是真正的预测**：只用出口时它排在第 81 位；加入进口后，BRIDGE 把它排在第 96 百分位。它的出口 83% 流向美国一侧，进口 32% 来自中国一侧，正是「从一侧进口、向另一侧出口」的桥接位置。

## 二、连接者识别（2018–2023 年平均）

| 国家 | CONN 百分位 | BRIDGE 百分位 | 原 GeoC 百分位 | 出口到美国一侧 | 进口来自中国一侧 |
|---|---|---|---|---|---|
| 越南 | 0.84 | 0.85 | 0.75 | 0.32 | 0.57 |
| 墨西哥 | 0.69 | **0.96** | 0.84 | 0.83 | 0.32 |
| 波兰 | 0.85 | 0.29 | **0.18** | 0.20 | 0.22 |
| 中国 | 0.87 | 0.71 | 0.88 | 0.25 | 0.46 |
| 印度 | 0.62 | 0.82 | 0.92 | 0.24 | 0.68 |

- **CONN 与 BRIDGE 度量的是连接的两种形态**：
  - CONN 是「两边都做生意」，例如波兰；
  - BRIDGE 是「从一边买、向另一边卖」，例如墨西哥；
  - 越南两者都高。
- 两者相关 0.49，应当作为两个维度同时使用，而不是合成一个指数。
- 原 GeoC 对墨西哥、印度并不差，主要问题在波兰（第 18 百分位）。原 GeoC 与 BRIDGE 的相关为 0.62，与 CONN 只有 0.43，说明它更接近「桥接」而不是「平衡」。

## 三、描述性发现（不涉及增长，但与中国政策直接相关）

| 国家 | CONN 2005 → 2023 | BRIDGE 2005 → 2023 |
|---|---|---|
| 中国 | **0.78 → 0.56** | 0.31 → 0.35 |
| 越南 | 0.39 → **0.61** | 0.34 → 0.46 |
| 墨西哥 | 0.32 → 0.47 | 0.41 → **0.54** |
| 波兰 | 0.24 → **0.72** | 0.06 → 0.23 |
| 印度 | 0.49 → 0.42 | 0.28 → 0.42 |

**中国的跨阵营平衡度在下降，而连接者经济体的连接度在上升。**这与贸易转移文献的发现一致：中美脱钩压力下，越南、墨西哥等承接了「中国一侧进口、美国一侧出口」的桥接角色。对中国而言，这意味着外部循环的「跨阵营」部分正在部分转移到第三方连接者手中。这是后续双循环分析的关键背景事实。

## 四、局限与说明

1. **C2 的改善有限**（0.44 → 0.35）。固定本国立场之后，GeoV_F 仍与立场极端程度相关。这不完全是机械关系：立场极端的国家，伙伴本来就更可能离它远。GeoV_F 满足登记标准，但不应被描述为「完全不受立场影响」。
2. **阵营划分依赖联合国大会投票**。投票不等于经济安全上的阵营；今后可以用制裁立场、安全同盟作为稳健性检验。
3. **没有看到关键投入品**。进口是总额，没有区分能源、芯片等关键品类。
4. **审查图 2 中波兰与摩洛哥的标签重叠**，数值不受影响。
