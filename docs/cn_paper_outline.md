# 研究大纲（第三版）：开放条件下的现代化联动及其结构转型

**题目**：《开放条件下的现代化联动及其结构转型——基于发展中国家的经验证据（1991—2023）》
**篇幅**：正文约 2.2–2.5 万字；正文 4 张图、5 张表；附录若干
**目标期刊**：《世界经济与政治》《国际经济评论》《当代亚太》；理论部分可与「关系转向」的讨论对话
**方法基础**：Aizenman、Ito 和 Saadaoui（2026，NBER WP 35242）的增长方程（方程 1）
**核心证据**：第十二轮事前登记检验（`docs/preregistration12.md`、`docs/results_vs_prereg12.md`）
**条件与边界的证据**：第一至十一轮（`docs/falsification_log.md`）
**旧版本**：第二版「承诺与约束的分离」存档于 `docs/cn_paper_outline_v2_separation.md`
**表述原则**：中性学术表述；不做因果宣称（写作「稳健的联动证据」）；不做敏感归因（写作「外部环境变化」「立场差异」）。

## 二、各部分详细设计

### 引言（约 2,500 字）

1. **现实起点**：全球南方群体性崛起；南南贸易占发展中国家出口的比重从 1990 年代初的约 35% 升至 2020 年代的约 62%（图 1b）。
2. **理论问题**：
   - 经典现代化理论把各国现代化视为沿同一阶梯攀升的独立单元；
   - 依附论和世界体系论承认关系，但把关系理解为中心对外围的等级性带动；
   - 多元现代性理论承认道路多样，但分析单位仍是单个文明或国家。
   - **三者都没有回答**：开放条件下，一国现代化在多大程度上取决于其他国家的现代化？这种依存是否只来自中心国家？
3. **本文的回答**：命题一至四（一句话各一条）。
4. **贡献**：
   - 理论上：提出「现代化联动的结构转型」，把「关系性认知」转化为可检验的命题；
   - 经验上：在原作者的增长方程中引入伙伴增长及其南北分解，采用事前登记、置换检验和区域×年份 FE；
   - 方法上：所有检验先登记后估计，零结果照实报告。
5. **结构安排**。

### 第一部分：文献与理论谱系（约 4,000 字）

| 理论 | 分析单位 | 对国家间关系的理解 | 本文的对照命题 |
|---|---|---|---|
| 经典现代化理论（罗斯托、英克尔斯等） | 国家 | 各自独立，路径线性 | 命题一：联动存在 |
| 依附论、世界体系论（弗兰克、阿明、沃勒斯坦） | 世界体系 / 中心—外围 | 等级性，带动与剥削来自中心 | 命题二、三：南南联动存在，来源在多元化；单位强度差异的证据不够稳健，放在讨论中 |
| 多元现代性（艾森斯塔特） | 文明 / 国家 | 路径多样，关系不是重点 | 命题四：关系结构决定联动 |
| 关系性认知（国内关系理论；徐秀军等关于现代化「关系转向」的讨论） | 国家间关系 | 空间依存、联动发展、多维互动 | 本文提供经验支撑并补充条件 |
| 开放宏观与增长溢出文献（Arora 和 Vamvakidis 2005 等） | 国家 | 伙伴增长的溢出 | 本文的方法基础，并加入南北分解与结构转型 |

**写作要点**：
- 依附论部分要写得公允：单位系数上北方高于南方，点估计稳定，但控制共同冲击后的登记检验未达显著（p = 0.064），所以只在讨论中提及「与等级性的解释一致」，不作为发现；
- 关系性认知部分：本文不重复阐释，而是指出它需要回答的经验问题，即联动是否存在、来源是什么、条件是什么。

### 第二部分：理论框架与研究假设（约 3,500 字）

1. **联动的来源分解**：一国从伙伴处得到的联动贡献 = θ × w × g。其中：
   - θ：单位联动强度；
   - w：关系密度，即贸易份额；
   - g：伙伴增长。
2. **三条传导渠道**（机制说明，不单独检验）：外部需求、中间品与供应链、技术和知识扩散。
3. **从分解推出结构转型**：只要南方的 w 和 g 上升，南方的贡献就会上升；无论 θ_S 与 θ_N 是否相等，都可能超过北方。**结构转型不以南北单位强度的比较为前提**。
4. **研究假设**：对应登记 L1–L5。
   - L1、L4 为核心假设；
   - L2（开放度）、L3（时期）、L5（中国）为延伸假设。
5. **联动的条件**：
   - 联动以实际经济关系为载体，因此具有区域性；
   - 制度规则只有落到实际关系上才会影响联动。

### 第三部分：研究设计（约 3,000 字）

- **样本**：117 个发展中国家，1991–2023 年，3,565 个观测（表 1）。
- **方程**：原作者方程 1，加入伙伴增长：
  g_it = φ g_i,t−1 + ρ ln y_i,t−1 + β X_i,t−1 + θ g^P_it + μ_i + τ_t + ε_it
- **关键变量**：
  - g^P：伙伴加权增长，权重为 t−3 至 t−1 年出口份额的平均（前定权重）；
  - g^S、g^N：南方、北方伙伴部分，g^P = g^S + g^N；
  - 北方为 23 个高收入经济体。
- **识别策略**：
  1. 年份 FE 吸收全球共同冲击，区域×年份 FE 吸收区域共同冲击；
  2. 前定权重，避免本国增长影响权重；
  3. 置换检验：随机打乱伙伴权重 200 次，排除「任何加权平均都显著」的可能；
  4. 事前登记与 Holm 多重检验校正。
- **数据来源**：GMD（增长与控制变量）、IMF IMTS（双边贸易）。

### 第四部分：实证结果（约 5,000 字）

1. **联动存在：同时报告上限与保守估计**（表 2 列 1–2、表 2b；图 2）：
   - **上限**：国家 + 年份 FE 下 θ = 0.63（p < 0.01），在各种子样本中都稳健，通过置换检验（置换 θ 的第 95 百分位只有 0.10）。由于贸易伙伴高度集中在本区域，这一量级包含区域共同成分。
   - **保守估计**：只用区域外伙伴、1997–2023 年、区域×年份 FE，θ_OUT = 0.32（p = 0.003，95% 区间 0.11–0.53；第十五轮登记检验 C1）。三种各自排除共同冲击的设计（区域外伙伴 0.20、1997 年以后的区域×年份 FE 0.24、滞后一期 0.20）量级接近，都在 0.2–0.3。
   - 全样本区域×年份 FE 的 0.31 对 1991–1996 年转型经济体敏感（第十四轮诊断，表 44），所以正文以保守估计为准，不再把「全样本区域×年份 FE」作为稳健性依据。
   - **表述**：「发展中国家的增长与贸易伙伴的增长显著同步；扣除区域共同冲击后仍有约 0.2–0.3 的联动」。「联动发展」对应相互依存的状态与同步性，**文章不主张传导的因果强度**。
2. **南南联动与南北差异**（表 2 列 3–4；图 2）：
   - θ_S = 0.60；保守设定下区域外南方伙伴 0.29（p = 0.003，辅助项）；
   - θ_N = 1.04，差值 −0.44（p < 0.05）。但控制大宗商品周期和全球金融周期后，登记检验 E1 为 −0.40（p = 0.064），未达显著；按事先约定，**南北强度差异只放在讨论或脚注**。
3. **稳健性**（表 3；图 3）：
   - 固定基期权重、进出口合计权重、剔除 2009 和 2020 年、剔除中国：都稳健；
   - 伙伴增长滞后一期后不显著，只用区域外伙伴时约为 0.20：这两项并入上文的「保守估计」一起讨论，而不是作为孤立的减弱。
4. **延伸假设**（表 2 列 5–6）：
   - 开放度调节方向一致（0.23，原始 p = 0.023，Holm 后 0.068），写作「提示性证据」；
   - 联动弹性没有随时期上升（0.73 对 0.55）；
   - 中国专项的带动未检测到，并说明检验力的局限。

### 第五部分：联动的结构转型（约 3,000 字）

- **图 1(a)**：南方贡献占比由 33%（1991–2000）升至 65%（2001–2010）、66%（2011–2023）；
- **图 1(b)**：南方伙伴的出口份额由 35% 升至 62%，其中对华份额由 2% 升至 12%；
- **表 4**：分解表；
- **解读**：联动强度没有变（L3），变的是关系结构，这正是结构转型的含义；
- **两种口径**：若南北弹性相同，南方贡献占比只由伙伴加权增长决定，为 46% → 77%；若用估计的南北弹性，为 33% → 66%。两种口径下「南方成为主要来源」都成立，所以这一结论不依赖南北强度差异是否存在；
- **与 θ 的水平无关**：在南北弹性相同的口径下，南方占比只取决于贸易份额和伙伴增长，只要求 θ > 0。θ 从 0.6（上限）降到 0.2–0.3（保守），改变的是联动贡献的绝对量，不改变南方占比的变化方向。所以**关系结构的转变是全文最稳健的证据**，联动的存在是它获得意义的前提；
- **联动是多源的**（第十三轮，表 4b）：
  - 从南方伙伴增长中拆出中国后，其余南方伙伴的联动为 0.64（区域×年份 FE 下 0.30）；
  - 拆出各国最大的南方伙伴后为 0.94（0.51）；
  - **两项只用来说明「拆出后其余南方伙伴的联动仍然存在」，系数大小不作比较**：分散组合比单个伙伴更贴近共同冲击，系数更大本身就可能来自共同冲击的残留；最大伙伴与其余伙伴的系数差异没有检验过。相关讨论最多放在脚注里；
  - 最大的南方伙伴中，中国占 19%，其余依次为印度、俄罗斯、南非、巴西等。
  - 结论：南南联动不依赖单一的南方大国，**没有形成新的单一中心**。这回应「新依附」的质疑，对应「共同性」。
- **中国的位置**：中国是南方关系比重上升的重要组成部分（对华出口份额约 2% 升至约 12%）。但中国的单位联动系数估计不精确（0.26，SE 0.22），不能说「显著带动」，也不能说「没有带动」；南南联动的证据不依赖中国。

### 第六部分：联动的条件（约 2,500 字）

- **载体是实际经济关系**：区域外伙伴联动较弱（图 3），中国—东盟贸易持续相对上升（第九轮）。
- **规则的独立作用有限并递减**（图 4a、表 5）：
  - 约束性深度的贸易效应，在政治立场相近的国家对之间，由 1990 年代的约 8% 降至 2006 年以后的约 2.5%；
  - 在立场差异大的国家对之间始终接近 0；
  - RCEP 生效四年内未检测到显著的贸易增量（第九轮）。
- **外部环境变化下的关系调整**（图 4b）：立场差异大的国家对之间的贸易，相对 2021 年，2017 年高约 7%，2025 年低约 8%。

**讨论要点（放在第六部分末尾或结论前，不作为发现）**：
- 1991–1996 年转型经济体的同步崩溃，有文献解释为原有生产和供应关系的中断（Blanchard 和 Kremer 1997 的「无组织化」）。按这种理解，那一时期的区域同步是关系依存的极端表现，只是方向为负；区域×年份 FE 可能因此过度控制。
- 这是看到结果之后的解释，现有设计无法把它和外生的区域冲击区分开，只能在讨论中提出，不用来恢复任何判定。

### 结论与政策含义（约 2,000 字）

1. **结论**：
   - 联动存在；
   - 南南联动存在（单位强度的南北比较不作为结论）；
   - 联动来源正在从北方转向南方；
   - 联动以实际经济关系为载体。
2. **理论含义**：「现代化联动的结构转型」，即联动来源的多元化与去中心化。
3. **政策含义**（中性表述）：
   - 深化南南经贸关系与区域合作；
   - 制度建设要落到实际经济关系上：贸易便利化、规则利用率；
   - 扩大开放是参与联动的前提（提示性证据）；
   - 联动意味着共同发展，也意味着风险共担：加强发展中国家之间的宏观政策协调。
4. **局限**：
   - 同期联动不能完全排除共同冲击；区域×年份 FE 下的结果对 1991–1996 年转型经济体样本敏感；
   - 联动的区域性较强；
   - 中国专项效应未识别；
   - 仅用增长率刻画现代化。

| 不说 | 说 |
