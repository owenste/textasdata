## 一、全文的论证链（一页纸版本）

```
研究问题：全球南方国家为什么大量签署「有约束力」的规则，而这些规则的经济作用又如此有限？
   │
前提一  开放的协调收益（合作为发展）
前提二  发展导向阶段需要保留政策空间（自主开放），且各领域的自主价值不同
   │
机制    承诺与约束的分离：以文本承诺获取协调收益，以时间上的分离（推迟激活）和
        形式上的分离（软条款、排除争端解决）保留自主；分离强度由领域的自主价值决定
   │
推论二  政府采购（自主价值最高）分离最强、承诺最少          ← 系统证据（N3，p < 0.001）
推论三  分离普遍存在，南南与南北协定都有（9%–36%）          ← 系统证据（N1a：伙伴间无差别）
        时间分离在少数南方区域共同体中长达 10–37 年         ← 描述性证据 + 案例
推论四  经济反应跟随信号（签署）而非法律生效；与否决者无关；
        国内政策不必然改变；增长效应弱而不稳                ← 证据一致（第二至五轮）
   │
并列事实（推论一）  文本深度集中在南南区域共同体；东亚例外    ← 稳健描述，不由分离机制解释
异常    失败协定没有预期效应 → 协调信号的可信度需要解释
被否定  「分离在南南最强」「执行能力的伙伴非对称驱动分离」（第六轮 N1a）
   │
贡献    OPE：内向型 / 外延型制度型开放从两种类型发展为一个过程的两个环节，可测量、可证伪
        OEP：在「国内制度 → 国际承诺」之后，补上国家可控的「激活」环节
        全球南方：南方国家大量参与规则文本的制定，但规则的约束普遍被分离、按领域选择性激活
```

## 二、章节大纲

### 一、引言（约 2,500 字）
1. **现实起点**：二十大报告「稳步扩大规则、规制、管理、标准等制度型开放」；全球南方的协定越来越「深」。
2. **困惑**（由三个已知事实构成）：
   - 全球南方已把大量开放写进「有约束力」的规则，其中绝大部分来自南南协定；
   - 但这些规则的经济作用有限：增长效应不稳健，国内政策也看不出随承诺改变；
   - 贸易却在协定签署后、生效前就开始变化。
   这三点用锁定理论、发展空间理论都解释不了。
3. **本文的回答**：承诺与约束的分离（一句话）。
4. **贡献**（三条，同第七部分）。

### 二、理论：从前提到推论（约 5,000 字）
**2.1 既有解释及其困难**（约 1,500 字）
- 锁定理论：预测北方伙伴更重要、政策逆转减少、否决者重要 → 与事实不符；
- 发展空间理论：能解释领域选择，不能解释格局与后果；
- 区域扩散：能解释集聚，不能解释落差与后果；
- 开放政治经济学（徐秀军 2024；徐秀军、罗仪馥 2024）提供了「内向型 / 外延型制度型开放」「自主开放」的概念，但还没有给出二者关系的机制；
- 开放经济政治学（Lake 2009）的链条止于国际承诺达成，默认承诺即约束。

**2.2 概念**：约束性承诺的环节拆分（义务、精确性、授权；Abbott et al. 2000）+ 激活；时间上的分离与形式上的分离。
**2.3 三个前提与机制的推导**（见一页纸版本）。
**2.4 四个推论**（写成可证伪的形式，每个推论写明「如果观察到什么，就说明推论错了」）。
**图 0（自绘）**：前提 → 机制 → 四个推论的框架图。

### 三、测量与数据（约 3,000 字）
**3.1 约束性深度**：六个领域；DESTA 时间线 + 世行 LE 编码 + 校准概率；领域并集。**表 1**。
**3.2 文本深度与激活深度**：本文的 D 以文本（世行 LE）为基础，经两类修正向激活深度靠近：
- 人工核对：南方共同市场按议定书生效时间起算；中国—冰岛按原文改为无约束力（**表 2**）；
- 系统修正：服务从世行记录的服务生效日起算。

所以 V0 → V2 的变化本身就是「分离」的一个度量。
**3.3 效度与局限**：与世行约束性条款数的 Spearman 相关为 0.82–0.88；2005 年以前的水平偏高；D 的上限为 6。

### 四、格局事实（推论一）与领域选择（推论二）（约 4,500 字）
**4.1 规模**：**图 1**（`cn_fig1_scale_source.png`）。2023 年平均 4.6/6；以 2005 年以后的趋势为主。
**4.2 伙伴：南南为主，且以区域共同体为骨架**：
- 图 1 的分解 + **图 4**（`cn_fig4_sensitivity.png`）+ **表 3**（`tab28_cn_corrections.md`）；
- 论证：只来自南北协定的仅占 5%；只保留南南双边协定则升至 42% → 文本深度集中在南方区域共同体。这是稳健的格局事实；第六轮检验表明它**不能**用「南南协定更容易分离」来解释，论文用区域扩散、区域共同体作为承诺平台的制度便利来说明，并标注为解释性而非检验性。

**4.3 区域：东亚的例外**：**图 2**（`cn_fig2_regions.png`）。东亚只来自南南 4%、只来自南北 16%，是唯一与北方伙伴深度绑定的区域；解释（出口导向经济体更愿意与北方伙伴深度绑定）尚待独立检验，写作时标注为推测。
**4.4 领域：政府采购是分离最强的领域**：**图 3**（`cn_fig3_domains.png`）+ **图 6A**。政府采购在南南（0.38）和南北（0.33）协定中覆盖都最少；即使写进文本，也最不可能有约束力（N3），符合推论二。

### 五、推论三（修订）：分离普遍存在，强度由领域决定（约 4,000 字）
**5.1 案例**：南方共同市场的时间分离（14–33 年）；中国—冰岛的形式分离（**表 2**；**图 5** 中巴西一格）。
**5.2 系统证据（第六轮登记检验，`tab29_separation_tests.md`，**图 6**、**表 4**）**：
- 形式分离普遍存在：写进文本但无完整约束力的比重为 9%–36%，南南与南北协定之间没有差别（N1a 不支持，如实报告）；
- 政府采购是分离最强的领域：协定内有约束力的概率低 17 个百分点（N3，p < 0.001）；
- 时间分离：登记检验不显著；描述性上集中在五个南方区域共同体（APTA 37 年、CARICOM 29 年、SADC 22 年、MERCOSUR 14 年、EAC 10 年）。

**5.3 对理论的修正**：放弃「执行能力的伙伴非对称」作为分离的驱动；分离由领域的自主价值驱动。这一节要写明修改是按事先登记的规则做出的。

### 六、推论四：分离的经济后果（约 3,500 字）
**6.1 经济反应跟随信号而非法律生效**：**表 5**（`tab24`、`tab25` 的基准与四种聚类）。签署后、生效前贸易已增长（0.021，p = 0.005）。
**6.2 反应与批准难度无关**：否决者的调节为 0（`results_vs_prereg5.md` H1）。
**6.3 国内政策不必然随承诺改变**：承诺前后国内投资政策无可检测变化（`results_vs_prereg4.md` E3；第一轮 P4：29 个事件中 21 个没有变化）。
**6.4 增长效应弱而不稳**：设定曲线中只有 24% 的设定显著；保守设定下不显著（附表）。控制在 800 字以内。
**6.5 异常**：失败协定没有预期效应；欧盟协定的待生效期没有效应。如实写出，并说明它们对框架的含义（协调信号的可信度需要解释）。

### 七、中国在分离格局中的位置（约 2,000 字）
- **图 5**（`cn_fig5_cases.png`）；`tab23` 第四、五节（修正后）。
- 中国：起步晚（2004 年）；主要北方伙伴是新西兰、瑞士、冰岛、澳大利亚；修正后 2023 年为 5 个领域；政府采购没有任何约束性承诺，是形式分离的典型。
- 比较：越南经由欧盟—越南协定和 CPTPP 激活了政府采购（分离最小）；巴西的约束长期停留在文本层面（时间分离最大）。
- 与制度型开放的对话：从「文本对接」到「激活执行」，政府采购是关键领域；本文不评价中国路径的成败，只提供比较坐标。

### 八、结论（约 2,000 字）
1. **结论**：承诺与约束的分离是全球南方参与国际规则的一般特征，分离强度由领域决定（政府采购最强），它解释了规则的落差与有限的经济后果；南南区域共同体作为主要承诺平台是与之并列的格局事实。
2. **理论贡献**：见一页纸版本。
3. **政策含义**（按证据层次写，见 `cn_paper_theory_core.md` 第十节）：
   - 系统证据：评估制度型开放要区分「写进文本」与「产生约束」，南北协定同样适用；政府采购是「最后一公里」，适合分级激活；不宜以增长预期推销深度协定；
   - 描述性证据与推演：南南区域共同体的短板在激活，南南合作可以把激活能力建设作为抓手；
   - 理论推演：自贸试验区作为局部激活机制；条件激活条款的设计价值；
   - 风险：分离长期不激活侵蚀可信度；不能作为回避承诺的理由。
4. **局限**：框架是溯因提出的；核对样本小；2005 年以前的水平偏高；贸易关联不是因果；东亚例外的解释待检验；有两项异常。
5. **未来研究**：扩大文本—激活核对；检验「出口导向 → 接受执行」；过程追踪。
