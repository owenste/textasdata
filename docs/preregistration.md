# 事前登记：承诺校准框架的检验方案

**登记时间**：2026-09-23，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有对 P1–P4 做过任何检验，也没有运行过下文 A1–A5 的替代解释检验。任何偏离本方案之处，都将在 `docs/results_vs_prereg.md` 中逐条列出。

## 0. 通用设定（除非另有说明）

- **样本**：发展中国家（世行 1995 年非高收入，`dev = 1`），1990–2023 年，人口 ≥ 200 万（`data/clean/panel_main.csv`）。
- **估计**：双向固定效应（国家 + 年份），国家聚类标准误。
- **控制变量**：CTRL = L.增长、L.ln实际GDP、L.投资率、L.ln人口、L.人口增长、L.通胀、L.国家能力、L.人力资本。
- **深度**：主设定 D（`L_D`，原始单位 0–6，不标准化，以便计算拐点）。
- **显著性**：主检验以 5% 双侧为准；p < 0.10 记为「弱支持」。
- **随机种子**：20260923；自助法为按国家整群抽样。

## 1. 倒 U 形的替代解释检验（A1–A5）

**基准**：g = β1·D + β2·D² + CTRL + FE。已知结果：β2 = −0.0023（p = 0.001），拐点 3.59。

| 编号 | 替代解释 | 检验 | 倒 U 形「通过」的标准 |
|---|---|---|---|
| **A1** | 反向因果：增长先下滑，才去签深度协定 | 事件研究。事件 = 某国 D 单年上升 ≥ 1 的年份。事件时间 k = −5…+5，两端合并（≤ −5、≥ +5），参照期 k = −1。事件按跃升后的深度分两组：**浅（跃升后 D ≤ 3）** 与 **深（D > 3）**，各自一套事件时间虚拟变量。控制 CTRL，双向 FE | 两组的事件前系数（k = −5…−2）联合检验 p > 0.10。**附加预测**：浅组的事件后平均效应（k = 0…+4 的均值）> 深组 |
| **A2** | 构成效应：中东欧入盟国拉低了高深度区间 | 剔除 POL、HUN、CZE、SVK、SVN、EST、LVA、LTU、BGR、ROU、HRV 后重估基准模型 | β2 < 0 且 p < 0.05 |
| **A3** | 区域层面的共同冲击（如拉美债务、转型衰退） | 把年份 FE 换成「区域 × 年份」FE | β2 < 0 且 p < 0.05 |
| **A4** | 高深度国家收入更高，增长本来就慢（收敛） | 控制中加入 L.ln实际GDP 的二次项和三次项 | β2 < 0 且 p < 0.05 |
| **A5** | 倒 U 形来自个别领域，而不是深度的「剂量」 | 把 6 个领域概率（滞后一期）同时放入模型，替代 D 与 D² | 描述性，无通过标准。**附加预测**：执行负担重的领域（竞争、采购、服务）系数 ≤ 0；可信度信号强的领域（投资、知识产权）系数 ≥ 0 |

**总判定**：A1 的事件前检验通过，且 A2、A3、A4 中至少 2 项通过 → 倒 U 形视为「稳健」；否则视为「可能由替代解释造成」，P1–P2 的结果相应降级解读。

## 2. P1：拐点随能力右移

- **能力 c 的主设定**：Hanson-Sigman 国家能力（`L_statecap`），在发展中国家样本中标准化。理由：模型中的 c 是「承担外部规则负担的能力」，最直接的测量就是国家能力；它的覆盖（1990–2015）也远长于 C_reform（2007 年起）。
- **模型**：g = β1·D + β2·D² + β3·D·c + β4·D²·c + CTRL + FE（L.国家能力已在 CTRL 中，即 c 的主效应）。
- **统计量**：拐点 d*(c) = −(β1 + β3·c) / [2(β2 + β4·c)]；检验量为 ∂d*/∂c 在 c = 0（样本均值）处的值。
- **推断**：整群自助法 499 次，取 95% 百分位区间。
- **判定**：∂d*/∂c > 0 且 95% 区间不含 0 → 支持；> 0 但区间含 0 → 方向一致、不显著；< 0 → 与预测相反。
- **辅助检验**：按各国国家能力均值的中位数分为高、低两组，分别估计二次模型，比较两组拐点（自助法求差值的 95% 区间）。
- **次要能力测量**（报告，不作判定依据）：C_reform、C_bti。
- **敏感性**：限定 ≤ 2016 年（国家能力在 2015 年后为延续值）。

## 3. P2：政策空间使「过度承诺」的代价减小

- **模型**：分段线性，节点 κ = 3.0（介于门限估计 2.5 和二次拐点 3.6 之间，事前固定）。
  g = γ1·D + γ2·(D − 3)⁺ + γ3·(D − 3)⁺·P + γ4·P + γ5·D·P + CTRL + FE
  其中 P = P_select（战略部门 − 制造业 FDI 限制度），在发展中国家样本中标准化。
- **判定**：γ3 > 0 且 p < 0.05 → 支持；γ3 > 0 且 p < 0.10 → 弱支持；γ3 ≤ 0 → 不支持。
- **次要 P 测量**（报告）：P_total、P_ka。
- **注意**：P 只覆盖约 51 个发展中国家，功效有限，事前承认。

## 4. P3：节奏的收益在低能力国家更大

- **模型**：g = D + S + S·c + CTRL + FE。S = S_jump_10（标准化），c = 国家能力（标准化）。
- **判定**：S·c 的系数 < 0 且 p < 0.05 → 支持；p < 0.10 → 弱支持。
- **次要**：c = C_reform。

## 5. P4：先试后签优于以签促改

- **事件**：发展中国家投资领域有约束力承诺的「首次进入」：`D_investments` 从 < 0.5 升到 ≥ 0.5 的第一年 t，限定 1995 ≤ t ≤ 2018（保证事件后有 5 年数据）。
- **国内规则变化**（主设定）：KAOPEN（`ka_open`，0–1）。
  前段 pre = ka_open(t−1) − ka_open(t−6)；后段 post = ka_open(t+4) − ka_open(t−1)。
- **分类**：
  - **先试后签**：pre > 0.05 且 pre ≥ post；
  - **以签促改**：post > 0.05 且 post > pre；
  - **无变化**：其余。
- **结果变量**：Δg = 事件后 5 年平均增长（t+1…t+5）− 事件前 5 年平均增长（t−5…t−1）。
- **模型**：Δg = α + θ1·先试后签 + θ2·以签促改 + L.ln实际GDP(t−1) + 事件年代虚拟变量；HC1 稳健标准误。
- **判定**：θ1 − θ2 > 0 且 p < 0.05 → 支持；p < 0.10 → 弱支持；≤ 0 → 不支持。若任一组事件数 < 10，只作描述性报告，不作判定。
- **次要国内测量**：Doing Business 规则修订次数（前段 vs 后段之和，仅 2004–2019 年可得）。
