# 事前登记（第九轮）：RCEP 分批生效与「规则层」的贸易效应

**登记时间**：2026-09-24，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有下载月度数据，也没有看过任何 RCEP 成员之间的双边贸易变化。

**此前看过什么（如实披露）**：
- 第七、八轮用过 IMF IMTS 的年度双边贸易数据（1990–2025），但只用来计算国家层面的份额（CONN、BRIDGE 等）。
- 看过的国家层面结果中，与本轮有关的一项：中国的 CONN 从 0.78（2005）降到 0.56（2023）。
- 从未计算过 RCEP 成员对的贸易在 2022 年前后的变化。
- 登记前只查看了月度数据的覆盖情况：中国、越南、日本三国，只看行数和起止月份，没有看数值。

---

## 一、为什么做这一轮

前八轮的跨国增长回归中，协定深度等结构变量都没有稳健效应。一个可能的原因是：总增长率离政策太远，而协定深度在国家之间的差异，大多不是政策变化造成的。

RCEP 提供了**一次明确的政策变化**，而且有一个理论上有用的特点：
- 15 个成员中，绝大多数国家对在 RCEP 之前已有自贸协定（东盟自贸区、东盟 10+1、中韩、中澳、中新、日澳等），关税空间很小，RCEP 新增的主要是**规则层**（原产地累积、统一规则、服务与投资承诺）；
- 只有**中日、日韩**两对是 RCEP 首次建立的自贸关系。

因此，RCEP 可以区分两条渠道：
1. **关税渠道**：新建立的自贸关系；
2. **规则层渠道**：已有自贸协定的国家对。

这对应「制度型开放」的核心主张：规则、规制、管理、标准层面的开放，本身有独立效果。

## 二、数据与样本

- **数据**：IMF IMTS 月度双边进口（到岸价，进口方报告），2017-01 至 2025-12。
  - 2026 年的月度数据较新，可能还会修订，只用于稳健性检验。
  - 下载脚本：`code/44_download_imts_monthly.py`。
- **样本国家**（进口方与出口方为同一组国家，构成方阵）：
  - IMTS 报告方中，2017-01 至 2025-12 的 108 个月里，至少有 100 个月有双边进口记录的经济体。
  - 剔除俄罗斯、白俄罗斯、乌克兰：2022 年战争和制裁与 RCEP 生效同时发生，是国家对层面的冲击，固定效应吸收不了。
  - 剔除缅甸：RCEP 对缅甸的生效存在争议，部分成员不承认。
  - 剔除区域汇总项。
- **结果变量**：进口额（美元），零值保留，缺失值剔除。

## 三、处理变量

**RCEP_ijt** = 1：i、j 都是 RCEP 成员（不含缅甸），且 t 月不早于两国中较晚的生效月。

「生效月」是生效后的第一个完整月份：

| 成员 | 生效日 | 生效月 |
|---|---|---|
| 澳大利亚、文莱、柬埔寨、中国、日本、老挝、新西兰、新加坡、泰国、越南 | 2022-01-01 | 2022-01 |
| 韩国 | 2022-02-01 | 2022-02 |
| 马来西亚 | 2022-03-18 | 2022-04 |
| 印度尼西亚 | 2023-01-02 | 2023-02 |
| 菲律宾 | 2023-06-02 | 2023-07 |

**分组**：
- **NEW_ij** = 1：中国—日本、日本—韩国（两个方向），即 RCEP 首次建立自贸关系的国家对。
- **D2021_ij**：该国家对在 2021 年的约束性深度，用 `depth_tools.dyad_depth` 计算（基础口径 V0；RCEP 不在 DESTA 02_03 中，不影响 2021 年的值）。在「已有自贸协定的成员对」中标准化。
- **CROSS_ij** = 1：两国分处两侧的成员对。
  - 位置 p 按第七轮的方法计算，取 2017–2021 年平均值；p ≤ 1/3 为中国一侧，p > 1/3 为另一侧。
  - 登记时已计算出的位置：
    - p > 1/3：日本 0.36、新西兰 0.36、韩国 0.43、澳大利亚 0.59；
    - 其余成员（东盟九国与中国）都 ≤ 1/3。
  - **说明**：没有一个成员达到第七轮「美国一侧」的标准（p ≥ 2/3），所以这里的 CROSS 衡量的是「中国一侧与非中国一侧之间」，不是「中美两个阵营之间」。

**同期其他协定**（控制变量）：
- OTHER_ijt = 1：该国家对在 t 年有 2017 年以后生效的 DESTA 协定处于生效状态（年度精度）。
- 这一项可以覆盖 CPTPP、中柬自贸协定（2022）、韩印尼 CEPA 等同期协定。

## 四、估计

PPML（pyfixest `fepois`）：

  M_ijt = exp(β·RCEP_ijt + γ·OTHER_ijt + α_ij + δ_it + θ_jt) · ε_ijt

- **固定效应**：
  - α_ij：有方向的国家对 FE；
  - δ_it：进口方×月份 FE，吸收各国的需求冲击、季节性、疫情和汇率；
  - θ_jt：出口方×月份 FE，吸收各国的供给冲击。
- **标准误**：按无方向的国家对聚类。

## 五、检验（第九族，Holm 校正）

| 编号 | 假设 | 模型 | 统计量 | 预测 |
|---|---|---|---|---|
| **H1** 平均效应 | RCEP 提高成员之间的贸易 | 主模型 | β | > 0 |
| **H2** 关税渠道 | 新建立的自贸关系效应更大 | 加入 RCEP × NEW | 交互项 | > 0 |
| **H3** 规则层的边际 | 在已有自贸协定的成员对中，原有规则越浅，RCEP 效应越大 | 剔除 NEW 国家对后，加入 RCEP × D2021 | 交互项 | < 0 |
| **H4** 跨侧连接 | RCEP 对跨侧成员对也有正效应 | 加入 RCEP × CROSS | β + 交互项 | > 0 |

**判定**：
- 方向正确，且 Holm 调整后 p < 0.05 → **支持**；
- 方向相反，且调整后 p < 0.05 → **证伪**；
- 其余 → **不显著**。
- H1 另有一个前提：事件研究的**签署前**提前项联合检验 p ≥ 0.10。否则即使系数显著，也只能判为「存在前趋势，不能解释为效应」。

**H2 的检验力提示**：NEW 只有 2 个国家对（4 个有方向的国家对），聚类标准误不可靠。结果照实报告，但事先说明它只是参考。

## 六、事件研究（H1 的前提检验）

- 对成员对，计算相对生效月的月数 k，按季度分组：q = ⌊k/3⌋，两端分别合并为 ≤ −12 和 ≥ +12。
- **基期** q = −6：对 2022-01 批次而言，是 2020 年 7–9 月，在 RCEP 签署（2020-11-15）之前。
- **前趋势检验**：q = −12…−7 的联合 Wald 检验。这些季度对 2022-01 批次都在签署之前。
- q = −5…−1 是「签署后、生效前」的窗口。第五轮发现过签署后、生效前的贸易效应，这里只作描述性报告。

## 七、稳健性（只报告，不改变判定）

1. 剔除中国—澳大利亚：2020–2023 年的贸易限制及其解除与 RCEP 生效同时发生，可能高估效应；
2. 剔除中国—美国：对照组中受关税战影响最大的国家对；
3. 年度数据版本：2017–2025 年，进口方×年、出口方×年、国家对 FE；
4. 安慰剂：只用 2017-01 至 2021-12 的数据，把生效时间假设为 2020-01；
5. 延长到 2026 年最新月份；
6. 剔除东盟内部的国家对：东盟自贸区的关税已接近零，是纯粹的规则层；
7. 用出口方报告的出口数据（镜像数据）。

## 八、不做的事

- 不根据结果修改样本规则、生效月的定义、分组阈值或固定效应结构；
- 不另外寻找「显著」的子样本；H1–H4 以外的分析都标注为探索性；
- 所有结果无论支持与否，一律报告。
