## 二、量级的综合

| 设计 | 排除共同冲击的方式 | θ |
|---|---|---|
| 国家 + 年份 FE，全部伙伴（第十二轮 L1） | 只排除全球共同冲击 | 0.63（上限，包含区域共同成分） |
| 区域外伙伴，年份 FE（第十二轮稳健性 6） | 去掉区域内伙伴 | 0.20 |
| 1997–2023 年，区域×年份 FE（表 44，探索性） | 区域×年份 FE，去掉转型初期 | 0.24 |
| 伙伴增长滞后一期（第十二轮稳健性 3） | 去掉同期冲击 | 0.20（不显著） |
| **区域外伙伴 + 1997–2023 年 + 区域×年份 FE（第十五轮 C1，登记）** | 三者同时 | **0.32，95% 区间 [0.11, 0.53]** |

**表述**：
- 国家 + 年份 FE 下约 0.6，作为包含区域共同成分的**上限**；
- 同时排除区域共同冲击与转型初期后约 0.2–0.3，这是**保守估计**，由第十五轮登记检验给出正式依据（0.32，95% 区间 0.11–0.53）；
- 正文把两个量级都写出来。

**说明**：
- 同一样本下，区域×年份 FE 的估计（0.32）高于国家 + 年份 FE（0.17，p = 0.097）。一种可能是：区域×年份 FE 去掉本国增长中的区域成分后，区域外伙伴增长的信号更清楚。这是事后解释，没有检验。
- 置信区间较宽（0.11–0.53），所以量级表述为「约 0.2–0.3」，不给精确值。

## 三、对论文的影响

1. **命题一的表述**：发展中国家的增长与贸易伙伴的增长显著同步；扣除区域共同冲击和转型初期后，仍有约 0.2–0.3 的联动。「联动发展」对应的是相互依存的状态和同步性，文章不主张传导的因果强度。
2. **命题三不受 θ 水平的影响**：
   - 在南北弹性相同的口径下，南方占比（46% → 77%）只取决于贸易份额和伙伴增长，只要求 θ > 0；
   - θ 从 0.6 降到 0.2–0.3，改变的是联动贡献的绝对量，不改变南方占比的变化方向。
   - 保守设定下，区域外南方伙伴的联动仍然显著（0.29，p = 0.003，辅助项）。
3. **主张的重心下移**：文章最稳健的证据是**关系结构的转变**；联动的存在是它获得意义的前提；联动的量级需要保守表述。
4. **讨论中可以提出、但不能用来恢复判定的解释**：1991–1996 年转型经济体的同步崩溃，文献中有一种解释是原有生产和供应关系的中断（Blanchard 和 Kremer 1997 的「无组织化」）。按这种理解，那一时期的区域同步是关系依存的极端表现，只是方向为负；区域×年份 FE 可能因此过度控制。这是看到结果之后的解释，现有设计无法把它和外生的区域冲击区分开。
