# 事前登记（第十三轮）：南南联动是多源的，还是依赖单一中心？

**登记时间**：2026-09-25，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有构造过「剔除中国」或「剔除最大南方伙伴」的南方伙伴增长，也没有估计过下文任何模型。

**缘起**：
- 第十二轮稳健性第 5 项「剔除中国」（`code/50_growth_linkage.py` 第 247 行，`d[d.ISO3 != "CHN"]`）只是把中国从**样本国**中去掉。
- 中国仍留在其他国家的伙伴权重中，并计入南方伙伴增长 g^S。
- 因此，那一项不能说明南南联动是否依赖中国。
- 本轮补做这项检验，并把它推广到「每个国家最大的南方伙伴」。

**此前看过什么（如实披露）**：
- 第十二轮的 θ_S = 0.595（区域×年份 FE 下 0.277），其中的 g^S **包含中国**；
- L5 用过「不含中国的全部伙伴增长」g^P,−CN 作为控制变量，但没有把南方部分单独拆出来；
- 南方伙伴出口中，对华份额的样本平均为 6.2%。

---

## 一、问题与理论含义

南南联动的来源是分散的（**多源联动**），还是集中在某一个或少数南方大国（**新的中心—外围**）？

| 结果 | 含义 |
|---|---|
| 剔除中国（或最大南方伙伴）后，θ 仍显著为正 | 南南联动是多源的，没有形成单一的新中心；对应「共同性」，并回应「新依附」的质疑 |
| 剔除后显著减弱或不显著 | 南南联动依赖少数中心；须如实写入命题三的限定 |

## 二、设定

与第十二轮完全相同：
- 原作者方程 1；
- 发展中国家，1991–2023 年；
- 伙伴权重为 t−3 至 t−1 年出口份额平均；
- 国家 + 年份 FE，国家聚类；另报区域×年份 FE。

**新变量**（权重不重新归一，所以各部分之和等于 g^P）：
- **g^CN** = w_i,CHN · g_CHN：中国的部分；
- **g^S,−CN** = g^S − g^CN：不含中国的南方伙伴部分；
- **g^TOP**：每个国家、每一年，按 t−3 至 t−1 年出口份额计算的**最大南方伙伴**的部分；
- **g^S,−TOP** = g^S − g^TOP：不含最大南方伙伴的南方部分。

## 三、检验（第十三族，Holm 校正）

| 编号 | 模型 | 统计量 | 预测 |
|---|---|---|---|
| **M1** 不依赖中国 | g ~ X + g^S,−CN + g^CN + g^N | g^S,−CN 的系数 | > 0 |
| **M2** 不依赖任何单一南方中心 | g ~ X + g^S,−TOP + g^TOP + g^N | g^S,−TOP 的系数 | > 0 |

**判定**：
- 方向正确，且 Holm 调整后 p < 0.05 → **支持**；
- 在此基础上，区域×年份 FE 版本也方向相同、原始 p < 0.05 → **稳健支持**；
- 方向相反，且调整后 p < 0.05 → **证伪**；
- 其余 → **不显著**，并在命题三中写明「南南联动的证据依赖中国（或最大南方伙伴）」。

**辅助项**（不参与判定，只报告）：
- g^CN 与 g^TOP 的系数；
- 系数比较：M1 中 g^S,−CN 的系数，对比第十二轮的 θ_S；
- 描述性分解：按第十二轮的方法，把南方贡献拆成「中国」与「其他南方伙伴」两部分，分时期报告。

## 四、稳健性（只报告）

1. 把中国从伙伴集合中完全去掉，并把其余伙伴的权重重新归一；
2. 同时把中国从样本国中去掉；
3. 固定基期权重（1990–1994）。

## 五、不做的事

- 不根据结果修改权重、南方定义或样本；
- 所有结果无论支持与否，一律报告，并据此修改大纲中命题三的表述。
