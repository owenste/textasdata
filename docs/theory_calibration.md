# 承诺校准：理论框架

**工作题目**：承诺校准：国家能力与深度贸易协定的非单调增长效应
*Calibrating Commitment: State Capability and the Non-Monotonic Growth Effects of Deep Trade Agreements*

**版本**：v1（2026-09-23），写于检验 P1–P4 之前。与事前登记文件 `docs/preregistration.md` 同一次提交。

---

## 1. 问题的重新表述

原研究计划问的是：什么决定了一国把 de jure 深度承诺**转化**为 de facto 制度变迁的能力？阶段 D–E 的证据否定了「转化能力放大承诺收益」这一机制（H2 被证伪），却发现了两个规律：深度与增长呈倒 U 形；推进节奏越渐进，增长越好。

这两个规律把问题的重心从承诺**之后**移到了承诺**之前**：

> **在能力约束下，什么样的承诺剂量、节奏与次序，才能使深度一体化带来增长？**

国家的能动性由此从「消化者」变为「校准者」：它的关键决策是签多深、多快，以及先在国内试点还是先对外锁定。

## 2. 模型

政府选择深度 d ≥ 0（有法律约束力的规则领域数）。增长净收益为

  G(d; c, s, p) = B(d) − K(d; c, s, p)

**可信度收益 B(d)**：B′ > 0，B″ < 0。国际承诺的价值在于约束政府自身、抵御国内利益集团压力，从而取信于投资者（Maggi & Rodríguez-Clare 1998, 2007）。收益边际递减：前几个领域（如投资保护、知识产权）已经发出了可信信号，后续领域的信号增量越来越小。

**约束与执行成本 K(d; c, s, p)**：K′ > 0，K″ > 0。成本包括两部分：一是丧失的政策空间（Rodrik 2008）；二是执行负担，即国家机器同时承担过多外部义务而导致的「过早承重」（Andrews, Pritchett & Woolcock 2017）。成本受三个国家条件调节：
- **能力 c**：∂K/∂d∂c < 0，能力越强，边际成本越低；
- **节奏 s**（渐进程度）：∂K/∂d∂s < 0，同样的深度分步到位，边际成本更低，因为国内配套制度有时间跟上；
- **保留的政策空间 p**：∂K/∂d∂p < 0，在战略部门保留干预余地，相当于给「承诺过度」装了一个安全阀。

**最优深度**由一阶条件 B′(d*) = K_d(d*; c, s, p) 决定。由于 B 为凹、K 为凸，G(d) 为倒 U 形，峰值在 d*。由隐函数定理：

  ∂d*/∂c = −K_dc / (B″ − K_dd) > 0，∂d*/∂s > 0，∂d*/∂p > 0

也就是说，能力越强、节奏越渐进、保留的政策空间越多，最优深度越深。

## 3. 可检验含义

| 编号 | 含义 | 来源 | 状态 |
|---|---|---|---|
| — | 增长与深度呈倒 U 形 | G 的形状 | **已观察到**（探索性），需通过替代解释检验 |
| — | 渐进推进伴随更高增长 | ∂K/∂s < 0 | **已观察到**（有条件） |
| **P1** | 拐点随能力右移：∂d*/∂c > 0 | 隐函数定理 | 未检验 |
| **P2** | 越过拐点后，政策空间使增长的下降更平缓 | ∂²K/∂d∂p < 0 | 未检验 |
| **P3** | 节奏的收益在低能力国家更大 | K 中 c 与 s 的替代关系 | 未检验 |
| **P4** | 先在国内试点、再做国际承诺（先试后签），优于承诺后被倒逼改革（以签促改） | 试点降低了承诺时的执行成本，相当于在承诺前提高了有效能力 c | 未检验 |

**P4 的理论意义**：原计划中的「试验主义能力」没有被放弃，而是被重新定位。试点的价值不在于承诺之后去消化规则，而在于承诺之前在国内演练规则，从而降低承诺的执行成本。这与「以签促改」的主流逻辑（Baccini & Urpelainen 2014）形成了对照：

| | 以签促改（主流） | 先试后签（本研究） |
|---|---|---|
| 次序 | 国际承诺 → 国内改革 | 国内试点 → 国际承诺 |
| 机制 | 外部约束克服国内阻力 | 国内演练降低执行成本 |
| 风险 | 承诺超出能力，导致执行失败或形式模仿 | 进展较慢，可能错过谈判窗口 |
| 典型 | 部分中东欧、拉美国家 | 中国自贸试验区、越南的分步开放 |

## 4. 与文献的关系

1. **Aizenman, Ito & Saadaoui (2026)**：他们发现协定数量对增长无效。本框架把问题推进两步：从数量到内容，再从内容到校准。
2. **深度一体化文献**（Mattoo, Rocha & Ruta 2020 等）：普遍预设越深越好。本框架预测非单调，并指出最优深度随国家条件而变。
3. **国家能力文献**：「过早承重」原本是对援助项目和国内改革的观察，本研究把它延伸到国际规则承诺，并提供跨国证据。
4. **试验主义与中国经验**（Heilmann 2008；Sabel & Zeitlin）：把试点定位为承诺前的校准工具，使中国经验成为一般机制的一个实例，而不是一个特例。

## 5. 研究诚信声明

- 倒 U 形与节奏效应是在阶段 D–E 的数据中**发现**的，属于探索性结果，本框架是为解释它们而构建的。因此，这两个结果**不能**被当作对本框架的证实。
- 本框架的证据只能来自事前登记的**新预测**（P1–P4）：它们在登记之前没有被检验过。
- 原 H2 被证伪这一事实，在论文中照实报告。
