# 事前登记（第十四轮）：控制全球大宗商品周期与全球金融周期后，南北联动差异是否仍然存在

**登记时间**：2026-09-25，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有下载大宗商品贸易条件和 VIX 数据的数值，也没有估计过下文任何模型。登记前只查看了两者的数据结构和覆盖年份：CTOT 的指标代码，VIX 的起止日期。

**缘起**：
- 第十二轮 L4 的辅助项显示：北方伙伴的单位联动（θ_N = 1.04）高于南方（θ_S = 0.60），差值 −0.44（p = 0.037）；区域×年份 FE 下差值为 −0.46（p < 0.05）。
- 这一差异可能来自等级性，即中心国家的带动更强；也可能来自**共同冲击**：北方增长与全球大宗商品周期、全球金融周期更同步，而各国对这两类周期的暴露程度不同，年份 FE 吸收不了这种异质性。
- 按增长溢出文献的常规做法，加入两类控制：
  1. 国家层面的大宗商品贸易条件冲击；
  2. 全球金融条件与本国资本开放度的交互项。
- 然后看 θ_S − θ_N 是否仍然显著。

**两种结果的写法（事先约定）**：
- 差值仍显著为负 → 「等级性」可以作为正文发现：南南联动已成为主要来源，但单位强度上的转型尚未完成；
- 差值不再显著 → 主线收缩为「联动来源的多元化」，删去「强度上尚未完成」这一层；理论增量依然成立。

## 一、设定

与第十二轮 L4 完全相同：
- 原作者方程 1；发展中国家，1991–2023 年；
- g^S、g^N 的权重为 t−3 至 t−1 年出口份额平均；
- 国家 + 年份 FE，国家聚类；另报区域×年份 FE。

在此基础上加入以下控制变量（全部是增长溢出文献中的常规变量）：

| 变量 | 定义 | 来源 |
|---|---|---|
| **ΔCTOT** | Δln 商品贸易条件指数，当年。指标 `CEMPI_CTOTXM_GDP`：商品出口与进口价格，按净出口占 GDP 加权；权重类型 `H_FW_IX`，即固定历史权重。 | IMF CTOT（Gruss 和 Kebhaj 2019） |
| **lnVIX × KA** | 当年 VIX 年均值取对数，乘以本国 t−1 年资本开放度 | CBOE；Chinn-Ito（0–1 标准化） |
| **i_US × KA** | 当年美国短期利率，乘以本国 t−1 年资本开放度 | GMD（`strate`，美国）；Chinn-Ito |
| **KA** | t−1 年资本开放度（主效应） | Chinn-Ito |

lnVIX 和 i_US 只随年份变化，主效应被年份 FE 吸收，所以只放交互项。

## 二、检验（第十四族，Holm 校正）

| 编号 | 统计量 | 预测 | 用途 |
|---|---|---|---|
| **E1** 南北差异 | θ_S − θ_N | < 0 | 核心：等级性能否保留为正文发现 |
| **E2** 南南联动 | θ_S | > 0 | 核心结果在加入共同冲击控制后是否仍成立 |
| **E3** 总体联动 | L1 模型加入同样的控制后的 θ | > 0 | 同上 |

**判定**：
- 方向正确，且 Holm 调整后 p < 0.05 → **支持**；
- 在此基础上，区域×年份 FE 版本也方向相同、原始 p < 0.05 → **稳健支持**；
- 方向相反，且调整后 p < 0.05 → **证伪**；
- 其余 → **不显著**。
- **E1 为「稳健支持」时**，等级性才作为正文发现；E1 为「支持（区域×年份 FE 下不成立）」时，按「与等级性的解释一致」写，不作为核心论点；E1 不显著时，主线收缩。

**样本**：加入控制变量后，缺少 CTOT 或资本开放度的观测会被剔除。另外报告两项：
- 在同一样本上**不加控制**的 θ_S − θ_N，用来区分「控制变量的作用」和「样本变化的作用」；
- 样本量。

## 三、稳健性（只报告）

1. CTOT 改用滚动权重（`H_RW_IX`）；
2. 用 ΔlnVIX 代替 lnVIX 水平；
3. 美国利率改为长期利率（GMD `ltrate`）；
4. 只加大宗商品控制；只加金融周期控制（分别报告）。

## 四、不做的事

- 不根据结果更换指标、权重类型或样本；
- 所有结果无论支持与否，一律报告，并按第一节事先约定的写法修改大纲。
