# 事前登记（第十五轮）：扣除区域共同冲击与转型初期后的保守联动量级

**登记时间**：2026-09-25，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有在「1997–2023 年 + 区域×年份 FE + 区域外伙伴」这一组合下估计过联动。

**此前看过什么（如实披露）**：三种设计各看过一次，但从未组合过。

| 设计 | 结果 | 出处 |
|---|---|---|
| 区域外伙伴，全样本，年份 FE | θ = 0.199（p = 0.045） | 第十二轮稳健性 6 |
| 1997–2023 年，区域×年份 FE，全部伙伴 | θ = 0.236（p = 0.044） | 第十四轮后的探索性诊断，表 44 |
| 伙伴增长滞后一期，全样本，年份 FE | θ = 0.203（p = 0.21） | 第十二轮稳健性 3 |

**目的**：
- 三种设计各自以不同方式排除共同冲击，量级都在 0.2 左右；
- 本轮用一项检验同时处理**区域共同冲击**和**转型初期（1991–1996 年）**，为保守量级提供一个正式依据；
- 国家 + 年份 FE 下的 0.6 左右，作为包含区域共同成分的上限，并列报告。

---

## 一、设定

- **方程**：原作者方程 1，与第十二轮 L1 相同。
- **样本**：发展中国家，**1997–2023 年**。
- **固定效应**：国家 + **区域×年份** FE；国家聚类。
- **伙伴增长**：**只用区域外伙伴**，g^P,OUT = Σ_{j 不在 i 所在区域} w_ij g_j。
  - 定义与第十二轮稳健性 6 完全相同（`code/50_growth_linkage.py` 中的 `linkage(..., drop=same)`）；
  - 去掉同区域伙伴后，其余伙伴的权重重新归一；
  - 区域为世界银行区域（`panel_main.csv` 的 region）；没有区域信息的伙伴按区域外处理。
- 权重为 t−3 至 t−1 年出口份额平均。

## 二、检验（单项，不做多重检验校正）

| 编号 | 统计量 | 预测 |
|---|---|---|
| **C1** 保守联动 | g^P,OUT 的系数 θ_OUT | > 0 |

**判定**：
- θ_OUT > 0 且 p < 0.05 → **支持**：约 0.2 的保守量级有正式依据；正文并列报告上限（约 0.6）与保守估计；
- p ≥ 0.05 → **不显著**：正文只报告「与区域共同冲击分开的联动证据较弱」，把 0.2 作为探索性的量级参考；
- θ_OUT < 0 且 p < 0.05 → **证伪**。

同时报告 θ_OUT 的 95% 置信区间，作为量级的表述依据。

## 三、辅助（只报告，不参与判定）

1. 同一设定下，区域外伙伴中的南方部分 θ_S,OUT 与北方部分 θ_N,OUT（g^P,OUT = g^S,OUT + g^N,OUT）；
2. 同一设定下，国家 + 年份 FE 的 θ_OUT，用于和上限对照。

## 四、不做的事

- 不更换起始年份、区域定义或固定效应结构；
- 结果无论如何都报告，并按第二节的规则修改大纲。
