# 事前登记（第十轮）：制度型开放能否缓冲地缘分化？——RCEP 的三重差分

**登记时间**：2026-09-24，以本文件首次提交的 git 提交时间为准。
**原则**：本文件提交之前，没有估计过下文任何模型。

**此前看过什么（如实披露）**：
- 第九轮（`docs/results_vs_prereg9.md`）看过 RCEP 成员对内部的「跨侧 vs 同侧」比较：
  - 生效后，跨侧 − 同侧 = −0.105；
  - 安慰剂期（2020–2021），跨侧 − 同侧 = −0.012；
  - 跨侧成员对的 β + 交互 = −0.072。
- **没有看过**：
  - 非成员的跨侧国家对在 2022 年前后的变化（下文 γ）；
  - 本轮的缓冲效应（成员跨侧对 vs 非成员跨侧对）；
  - 中国专项检验（K3）。
- 登记前查看了各国阵营位置的分布（只用联合国投票数据，不涉及贸易）：p > 1/3 的共 52 国，基本是欧洲、北美、日、韩、澳、新、以色列、土耳其。

---

## 一、问题与理论

**命题**：制度型开放的效果以地缘政治条件为前提。

2022 年以后，西方与其他经济体之间的贸易可能在分化。问题是：同处 RCEP 之内的跨侧国家对，比如中国、东盟与日、韩、澳、新之间，是否比 RCEP 之外的跨侧国家对下降得更少？

- **缓冲说**：共同的规则框架降低了政治风险、稳定了预期，所以跨侧成员对下降更少。预测 K1 > 0。
- **无关说**：地缘分化由安全考量驱动，规则框架挡不住。预测 K1 ≈ 0 或 < 0。

## 二、数据与样本

- 与第九轮相同：IMF IMTS 月度双边进口（到岸价，进口方报告），2017-01 至 2025-12，样本规则相同（`code/rcep_data.py`）。
- **新增规则**：剔除没有联合国投票理想点、无法划分阵营的经济体，例如香港、台湾、澳门。

## 三、变量

- **阵营**：p 取 2017–2021 年平均值；p > 1/3 为 W 侧（非中国一侧，52 国），其余为 C 侧。
- **XS_ij** = 1：两国分处 W、C 两侧（跨侧国家对，全样本定义）。
- **POST_t** = 1{t ≥ 2022-01}：「地缘分化期」。
  - 以 2022 年为界，因为俄乌战争、美国对华芯片出口管制（2022-10）、日韩跟进等集中在 2022 年以后；
  - 同时也与 RCEP 主批次生效时间一致，这是设计本身需要区分的对象。
- **RCEP_ijt**：同第九轮，按生效月分批。
- **CHN_ij** = 1：国家对的一方是中国。
- **OTHER_ijt**：同第九轮。

## 四、模型

PPML（pyfixest `fepois`），国家对 + 进口方×月 + 出口方×月 FE，按无方向国家对聚类：

  M_ijt = exp( γ·XS×POST + β1·RCEP + β2·RCEP×XS + λ·OTHER + FE )

四类国家对在生效后/2022 年以后的相对变化：

| | 非成员 | RCEP 成员对 |
|---|---|---|
| 同侧 | 0（基准） | β1 |
| 跨侧 | γ | γ + β1 + β2 |

**缓冲效应** = 成员跨侧对相对于非成员跨侧对的变化 = **β1 + β2**。

**中国专项模型**（K3）：在上式基础上加入
- XS×POST×CHN：允许中国参与的跨侧国家对有自己的分化趋势，比如中美、中欧；
- RCEP×XS×CHN。

**K3 的统计量** = β1 + β2 + β3，即中国—日、韩、新相对于中国—其他 W 侧国家的变化。
- **剔除中国—澳大利亚**：中国对澳的贸易限制在 2020–2023 年实施后又解除，与 RCEP 生效同期，会机械地抬高这一估计。这个剔除在看到任何结果之前决定。

## 五、检验（第十族，Holm 校正）

| 编号 | 假设 | 统计量 | 预测 |
|---|---|---|---|
| **K1** 缓冲 | RCEP 成员跨侧对的下降小于非成员跨侧对 | β1 + β2 | > 0 |
| **K2** 分化 | 2022 年以后，跨侧国家对普遍相对下降 | γ | < 0 |
| **K3** 中国的缓冲 | 中国与 RCEP 内 W 侧成员（日、韩、新）的贸易，相对中国与其他 W 侧国家，在生效后上升 | β1 + β2 + β3（剔除中澳） | > 0 |

**判定**：
- 方向正确，Holm 调整后 p < 0.05，**并且**通过对应的前趋势检验（见第六节，p ≥ 0.10）→ **支持**；
- 方向正确、显著，但前趋势检验未通过 → **「存在前趋势，不能解释」**；
- 方向相反，调整后 p < 0.05 → **证伪**（K1 证伪即「规则框架加剧而不是缓冲了分化」）；
- 其余 → **不显著**。

**这次对所有检验都设前趋势条件**（第九轮的教训）。

## 六、前趋势检验（按日历年的事件研究）

- 把 XS×POST、RCEP、RCEP×XS（K3 另加 CHN 项）换成按日历年的交互：年份 × 组别。基年为 2021 年。
- 组别：
  - 跨侧（K2）；
  - 成员同侧、成员跨侧（K1 的统计量是二者之和）；
  - K3 另加：中国跨侧、中国—RCEP 内 W 侧。
- **前趋势**：各统计量在 2017–2020 年的系数，做联合 Wald 检验。

## 七、稳健性（只报告，不改变判定）

1. 剔除美国：东盟对美出口的「转口」激增可能抬高非成员跨侧对，从而压低 K1；
2. K1 剔除中国参与的全部国家对：只看东盟—日、韩、澳、新；
3. K3 包含中国—澳大利亚；
4. POST 改为 2022-10（美国芯片出口管制）；
5. 镜像数据（出口方报告）；
6. 阵营阈值改为 p > 0.5。

## 八、不做的事

- 不根据结果修改 POST 的时点、阵营阈值、样本或固定效应结构；
- 其余分析一律标注为探索性；
- 所有结果无论支持与否，一律报告。
