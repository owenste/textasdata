**前两轮**：`docs/preregistration.md`（`598a65c`）、`docs/preregistration2.md`（`ca809d9`）；结果见 `docs/results_vs_prereg.md`、`docs/results_vs_prereg2.md`。

## 一、理论：两派的对立预测

IPE 文献对深度贸易协定有两种对立的看法：

- **锁定派**（lock-in / credibility）：发展中国家用有约束力的国际承诺把国内改革「锁住」，让投资者相信政策不会逆转（Büthe & Milner 2008；Baccini & Urpelainen 2014）。和北方大国签的协定执行力更强、更可信。
- **发展空间派**（development space）：深度协定，尤其是按北方模板签的南北协定，压缩了产业政策空间，承诺越深代价越大（Wade 2003；Shadlen 2005）。

本研究前两轮的结果显示：总体上既检测不到大的收益，也检测不到大的代价。本轮用三组检验去区分两派的**机制**：

| 检验 | 锁定派预测 | 发展空间派预测 |
|---|---|---|
| B1 南北 vs 南南深度 | 南北深度的初始收益更大 | 南北深度的收益递减更快（二次项更负） |
| B2 签署 vs 生效 | 效应在生效时出现（约束力起作用），签署后未生效期间没有 | （本身不作预测；用来检验「约束力」这一共同前提） |
| B3 政策反复 | 有约束力的深度降低政策逆转的概率 | （不作预测） |

## 二、通用设定

- 样本：发展中国家（与前两轮相同），1990–2023；双边模型的出口方为 120 个发展中国家。
- 所有右侧变量滞后一期；控制变量同前（增长模型用 CTRL 八项；政策反复模型用 L.lny、L.statecap、L.hc 以及结果变量的滞后水平）。
- 主设定：国家 FE + 年份 FE，国家聚类 SE。**区域×年份 FE 版本并排报告**；某项结论只有在两种 FE 下都成立（p < 0.05、方向相同）才称为「稳健支持」，只在年份 FE 下成立的称为「支持（不稳健）」。
- 深度的构造规则与主设定 D 相同（DESTA 条款 × 校准约束力概率，世行编码优先，领域并集 1 − Π(1 − p)），排除 EU-ACP 非对等安排。
- 随机种子 20260923。

## 三、B1：南北深度 vs 南南深度（权力不对称）

**北方国家**（1995 年的传统 OECD 高收入国家，共 23 个）：欧盟 15 国（AUT BEL DNK FIN FRA DEU GRC IRL ITA LUX NLD PRT ESP SWE GBR）、瑞士、挪威、冰岛、美国、加拿大、日本、澳大利亚、新西兰。

**构造**：
- 一个协定版本只要有任何一个北方成员，就归为「南北协定」，否则归为「南南协定」。
- D_N(i,t) = 国家 i 在 t 年已生效的全部南北协定按领域取并集，0–6；D_S(i,t) 同理，只用南南协定。
- 世行独有（DESTA 未对上）的协定按其世行成员名单同样归类。

**模型**：g = α1·D_N + α2·D_N² + β1·D_S + β2·D_S² + CTRL + FE（核心变量 4 个）。

**预测与判定**：
- **B1-L（锁定派）**：α1 − β1 > 0（进入承诺时，南北深度每个领域的增长收益更大）；判定：α1 − β1 > 0 且 Holm 调整后 p < 0.05 → 支持。
- **B1-S（发展空间派）**：α2 − β2 < 0（南北深度的收益递减更快）；判定：α2 − β2 < 0 且 Holm 调整后 p < 0.05 → 支持。
- 两项都支持、只支持一项、都不支持，分别报告；并报告 α2、β2 各自的估计。

## 四、B2：签署 vs 生效（约束力是否起作用）

**构造**：
- 「待生效深度」D_pend(i,t) = D_sign(i,t) − D(i,t)。其中 D_sign 把「已签署、t 年尚未生效、之后会生效」的协定也计入，从签署年起算。这样 D_pend 衡量的是**已签署但尚未生效的额外领域**，≥ 0。
- 签署年取 DESTA 的 `year`，生效年取 `entryforceyear`；签署年 ≥ 生效年的行没有待生效期。
- 世行独有协定没有签署日期，不计入 D_pend。

**B2-G（增长）**：g = γ1·D + γ2·D² + γ3·D_pend + CTRL + FE。
- 关键对比 Δ = γ1 − γ3（D = 0 附近，一个已生效领域与一个待生效领域的增长效应之差）。
- **判定**：
  - 「约束力机制」：Δ > 0 且 Holm 调整后 p < 0.05；
  - 「信号/预期机制」：γ3 > 0 且 p < 0.05，同时 Δ 的 p > 0.10；
  - 其余：无法区分。
- 另报告 γ3 的等价性检验（TOST，SESOI ±0.0025/领域，90% 区间）。

**B2-B（双边出口，PPML）**：X_ij = δ1·D_ij + δ2·D_ij² + δ3·D_ij,pend + 出口方×年份 FE + 进口方×年份 FE + 国家对 FE；按国家对聚类。D_ij,pend 按同一规则在国家对层面构造。
- 关键对比 δ1 − δ3，判定规则同 B2-G。
- 双边模型的区域×年份 FE 不适用（已有出口方×年份 FE），不做并排。

## 五、B3：政策反复（锁定的直接检验）

**B3a 资本账户逆转**：
- 结果 rev_ka(t) = 1{KAOPEN(t) < KAOPEN(t−1)}；样本限于 KAOPEN(t−1) > 0 的观测（开放度已为 0 的国家无法再逆转）。
- 模型：线性概率模型，rev_ka = θ·L.D_investments + L.KAOPEN + L.lny + L.statecap + L.hc + FE。L.D_investments 为投资领域被有约束力条款覆盖的概率（0–1）。
- 预测：θ < 0；判定：θ < 0 且 Holm 调整后 p < 0.05 → 支持。

**B3b 贸易政策逆转**：
- 结果 rev_tar(t) = 1{加权平均实施关税(t) − 关税(t−1) ≥ 1 个百分点}；只用相邻两年都有数据的观测。
- 模型：rev_tar = φ·L.D + L.关税 + L.lny + L.statecap + L.hc + FE。
- 预测：φ < 0；判定同上。

## 六、多重检验校正（第三族）

B1-L、B1-S、B2-G、B2-B、B3a、B3b，共 6 项，Holm 校正，**判定以调整后的 p 为准**。

- B1、B2 的 p 为关键对比（α1 − β1、α2 − β2、Δ、δ1 − δ3）的双侧 Wald 检验；
- B3 的 p 为 θ、φ 的双侧检验。
