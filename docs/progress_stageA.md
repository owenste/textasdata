## 一、结论先行

**谜题成立。** 在 122 个发展中国家中，1995–2020 年的平均承诺深度几乎不能解释相对美国的收敛幅度：

- 一元 OLS：斜率 = −3.9（稳健 SE 3.6，p = 0.27），**R² = 0.012**，Spearman ρ = −0.08
- 深度最高的三分之一国家内部，收敛幅度的四分位距（IQR）仍有全样本的 **77%**，这些国家的收敛幅度从 −151（委内瑞拉）到 +92（立陶宛）不等
- 控制 1995 年初始收入后，深度的偏 R² = 0.015，结论不变

判定标准在看到结果之前就写进了代码（`04_fig01_puzzle.py` 中的 `PRE_REGISTERED`）：R² ≥ 0.50 判为前提不成立；R² < 0.20 且高深度组 IQR 比 ≥ 0.60 判为谜题成立。

**深度的定义**：把某国当年所有生效协定取并集，数出其中覆盖了多少个「边境后」规则领域，再求 1995–2020 年的年度均值。用并集而不用协定个数，是因为协定个数正是 Aizenman 等 (2026) 自承粗糙的测量；用并集也避免了同一领域被多个协定重复计数。

**收敛的定义**：100 × [Δln 人均实际 GDP(i) − Δln 人均实际 GDP(美国)]。这个指标只用到各国自身的增长率，不需要跨国可比的价格水平。

**样本**：按世行 **1995 年**的收入分组剔除高收入国家。用当年分组而不用今天的分组，是为了不把波兰这类窗口内收敛成功的国家筛掉，否则会产生选择偏差。

## 四、需要导师知悉的三个测量问题

1. **世行 DTA 存在幸存者偏差。** 它基本只编码现仍生效的协定，已失效的旧协定缺失，例如波兰 1995–2003 年的深度被记为 0。所以主图改用覆盖历史协定的 DESTA，世行 DTA 只放在稳健性检验里。这一点偏离了原计划「以世行 DTA 为主」的设想。
2. **DESTA 只记录条款是否出现，不区分法律约束力。** 撒哈拉以南非洲有 35 国的深度均值恰好为 4.0，主要来自《洛美协定》这类援助型、不可执行的条款，因此这些国家的深度被高估了。阶段 C 构造 D 时，建议把两个库结合起来：世行 DTA 覆盖的协定用它的法律约束力编码，已失效的旧协定用 DESTA 补足。
3. **两个库的结论存在分歧，需要如实记录。** 改用世行 DTA 的有约束力深度后，斜率为正且统计显著（p < 0.01），但 R² 仍只有 0.08–0.13。其中 2020 年终点值这一设定的高深度组 IQR 比只有 0.52，按事先写定的标准判为「模糊」。也就是说，**深度与收敛并非完全无关，只是关联很弱**。这与 H1 的表述（「解释力弱」）一致，但 H1 的证伪条件要求检验「单独显著且稳健」，这需要到阶段 D 在面板中正式检验，本图不能替代。

对照组「生效协定个数」的 R² = 0.000，与 Aizenman 的发现一致，说明数量测量确实没有信息量。
