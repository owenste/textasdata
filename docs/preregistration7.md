# 事前登记（第七轮）：新地缘经济变量的构造规则与效度标准

**登记时间**：2026-09-24，以本文件首次提交的 git 提交时间为准。
**背景**：`docs/variable_audit.md` 发现原作者（Aizenman, Ito & Saadaoui 2026）的 GeoC 认不出连接者，GeoV 随本国投票立场漂移，且两者都只用出口。本轮登记新变量的**构造规则**和**效度标准**。
**原则**：
- 本文件提交时，进口数据还在下载，没有看过任何进口数据；
- 本轮只检验测量效度，**不看任何变量与增长的关系**；
- 增长框架中「原变量 vs 新变量」的比较另行登记。

**已知信息**（审查时已经看过，如实说明）：只用出口计算的跨阵营平衡度中，越南排第 5、墨西哥排第 81、波兰排第 14（2018–2023 年，120 国）。所以标准 C1 对越南、波兰不是完全「盲」的；对墨西哥的判断取决于进口数据，是真正的预测。

## 一、构造规则

**伙伴位置**（以中美两极为参照，逐年计算）：
p_jt = (理想点_jt − 理想点_中国,t) ÷ (理想点_美国,t − 理想点_中国,t)。
p ≥ 2/3 为「美国一侧」，p ≤ 1/3 为「中国一侧」，其余为「中间」。理想点来自 Bailey, Strezhnev & Voeten（2024 年 6 月版）。

**贸易数据**：IMF IMTS，报告方为 122 个发展中国家；出口 FOB、进口 CIF；1990–2025 年，美元。

**新变量**（i = 报告方，t = 年份）：

| 变量 | 定义 | 对应构念 |
|---|---|---|
| **CONN 跨阵营平衡度** | 2·min(T_US, T_CN) ÷ (T_US + T_CN)，T 为进出口总额中流向（来自）美国一侧、中国一侧的份额 | 双边都有往来的程度 |
| **BRIDGE 桥接度** | max{ √(m_CN · x_US), √(m_US · x_CN) }，m 为进口来源份额，x 为出口去向份额 | 「从一侧进口、向另一侧出口」的供应链桥接位置 |
| **GeoV_F 固定参照脆弱性** | Σ_j w_ij · \|p_j − p̄_i\|，w 为进出口总额份额，p̄_i 为 i 在 1990–2023 年的平均位置（固定，不随年份变化） | 与地缘政治上远离自己的伙伴的贸易暴露，不随本国立场漂移 |
| **DIST 远距离份额**（次要） | \|p_j − p̄_i\| > 1/3 的伙伴占贸易总额的份额 | GeoV_F 的简单版本 |

伙伴缺少理想点的贸易额不计入份额的分母（与原作者相同）。

## 二、效度标准（事先写定）

| 标准 | 检验内容 | 通过条件 |
|---|---|---|
| **C1 认出连接者** | 越南、墨西哥、波兰：2018–2023 年平均值在 122 国中的百分位 | 三国在 CONN 或 BRIDGE 中**至少一个**上都位于前三分之一，且三国在「CONN、BRIDGE 两者中较好的那个」上的平均百分位高于原 GeoC |
| **C2 不随本国立场漂移** | GeoV_F 与本国立场极端程度 \|p_own − 0.5\| 的相关 | 绝对值低于原 GeoV 的 0.44 |
| **C2b 中国** | 中国 GeoV_F 在 2015 → 2023 年的变化方向 | 与「固定立场」分解的结论一致（下降） |
| **C3 已知冲击** | 俄罗斯 2023 年相对 2021 年 | CONN 下降，且中国一侧的贸易份额上升 |

**使用规则**：
- C1 不通过 → 新的连接度变量不作为主变量，只作为报告；
- C2 不通过 → GeoV_F 不替代原 GeoV；
- 所有结果照实报告。

## 三、不做的事
- 不根据效度结果修改阵营门槛（1/3、2/3）、参照系或权重；
- 本轮不跑任何增长回归。
