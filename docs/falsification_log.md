## H1：承诺深度单独对增长的解释力弱

- **主设定**：D 系数 = 0.0044（SE 0.0030，p = 0.14），N = 3,465，117 国。
- **16 种变体**：3 个在 10% 水平显著，分别是宽松版 D、全样本（p = 0.047）、不控制国家能力；其余 13 个不显著，没有一个显著为负。
- **系统 GMM**：D = −0.0003（p = 0.96）；AR(2) 通过，Hansen p = 0.063（边缘）。
- **与协定数量赛马**：加入 EIA 协定数后，D 基本不变（0.0042）。
- **转化分析（Y1）**：KAOPEN 对投资领域 D 的斜率 ≈ 0（−0.0008，p = 0.94），即承诺深度与资本账户法律开放没有国家内部的关联。

**但线性模型掩盖了非线性：**
- **Hansen 门限**：以 D 为门限变量，γ = 2.52，自助法 p = 0.010。门限以下 D 的系数为 +0.0157，门限以上为 −0.0098。
- **二次项交叉验证**：D² 在三种口径下都显著为负（主设定 p = 0.001，门槛版 p = 0.009，只用世行 p = 0.032），拐点在 3.2–3.6 个领域。

**判定**：「线性解释力弱」未被证伪。但深度并非与增长无关：**浅层的规则承诺伴随更高的增长，超过约 3 个有约束力的领域后，增长回报递减乃至转负**。建议把 H1 修订为「深度与增长呈非单调关系」。这个发现是在数据中探索出来的（门限检验本身就是探索性的），需要在新样本或新时期上验证，不能当作事先预测的证实。

## H2：深度 × 转化能力 交互为正

- **主设定**：D×C = −0.0010（SE 0.0029，p = 0.72），N = 1,514，111 国，2007–2020。
- **16 种变体**：0 个显著。C 换成 BTI（专家评分）后仍不显著（+0.0003、+0.0014）。
- **边际效应图（图 2）**：在 C 的全部取值范围内，D 的边际效应置信区间都包含 0。
- **MM-QR**：9 个分位上 D×C 都不显著。
- **门限（以 C 为门限变量）**：p = 0.59，不存在门限。
- **异质性**：C 高、低两组中 D 的系数均不显著，组间差异也不显著（p = 0.41）。
- **转化分析（Y1）**：D_投资 × C = 0.0044（p = 0.61）。
- **系统 GMM**：D×C = −0.012（p = 0.10），但 Hansen 检验 p = 0.000，工具无效，不可信。
- **AIC/BIC**：加入 C 和 D×C 后，AIC、BIC 都变差。

**判定**：按研究计划的证伪条件（「交互不显著或为负 → H2 伪」），**在现有 C 的测量下 H2 被证伪**。

**需要说明的局限**：这些局限影响对这一证伪结果的解读，但不能用来推翻它。
1. C_reform 只测到「营商规则修订频率」，**「政策试验/试点扩散」这一面没有测到**，而它恰恰是「试验主义」的核心。
2. C 只覆盖 2007–2020 年，每国约 13 年，D 在这段时间的国家内部变化很小（许多国家已达上限 6）。
3. 研究计划第 6 节规定不作因果识别。如果要挽救 H2，必须先改进 C 的测量，然后**在新数据上重新检验**，而不是在同一数据上反复尝试各种 C 的定义直到显著。

## H3：战略部门保留政策空间的国家转化率更高

- **主设定**：D×P = 0.0062（p = 0.31），N = 452，51 国（受 OECD FDI 限制指数的覆盖所限）。
- **16 种变体**：3 个显著为正。C 用 BTI 时（N = 540，p ≈ 0.01），以及用 Driscoll-Kraay 标准误时（p = 0.036）；P 换成审查审批或资本账户口径时为负，但不显著。
- 没有任何设定出现显著的负相关。

**判定**：计划的证伪条件是「政策空间与转化率负相关」，**未触发**；但正向效应也不稳健。**H3 未被证伪，也未获支持**。样本只有 51 个发展中国家，统计功效有限。

## H4：同等终点深度下，渐进累积优于快速跃进

- **主设定（S_jump）**：S = +0.0043（p = 0.033），N = 1,677，110 国，已控制 D。S 每高一个标准差（推进更均匀），年增长率约高 0.43 个百分点。
- **16 种变体**：15 个显著为正，包括剔除中国、三种 D 口径、Driscoll-Kraay 标准误、全样本、剔除 DB 数据违规国。
- **唯一的例外正是研究计划的原定义 S_sd（−SD）**：+0.0050，p = 0.19，已控制总增幅。
- D×S = −0.0039（p = 0.09）：深度越高，渐进的好处越小。

**判定**：**有条件支持**。必须如实说明：
1. S_jump 是我在阶段 C 构造变量时定为主设定的，当时还没有跑任何回归，理由是 S_sd 与深度总增幅的相关达 −0.90（机械相关）。但这仍属于研究者的自由裁量。
2. S_jump 只在过去 10 年深度确有上升（≥ 0.5）时有定义，所以比较对象限于「正在一体化」的国家-年度。
3. 按计划的原定义，H4 不显著。

## 元证伪 1：转化能力 C 是否被 Hanson-Sigman 国家能力吸收

| 设定 | C 的系数 | D×C | 国家能力 |
|---|---|---|---|
| C 单独，不控制国家能力 | 0.0015（p = 0.32） | | |
| C 单独，控制国家能力 | 0.0015（p = 0.33） | | 0.0219（p = 0.21） |
| D、C、D×C，不控制 | 0.0023（p = 0.35） | −0.0014（p = 0.63） | |
| D、C、D×C，控制 | 0.0021（p = 0.42） | −0.0010（p = 0.72） | 0.0196（p = 0.27） |

**判定**：C 与国家能力的相关只有 0.09，控制国家能力后 C 的系数几乎不变，所以**不存在「被国家能力吸收」的冗余**。但 C 本身就没有解释力，加入后 AIC/BIC 都变差。按研究计划第 3 节「解释力不增即删」，**C_reform 应当删除或重新操作化**。BTI 版本也不显著，且与国家能力高度相关（0.74），不适合作替代。

## 元证伪 2：中国是否在所有设定下都是巨大正残差

| 设定 | 中国的排名（1 = 最大正残差） |
|---|---|
| 阶段 A 谜题图：深度与收敛的双变量回归 | **1 / 122** |
| 组间回归：只含控制变量（初始收入、投资、人口、通胀、国家能力、人力资本） | 15 / 117（+1.70 个百分点/年） |
| 组间回归：+D | 14 / 117 |
| 组间回归：+D、C、D×C（2007–2020） | 40 / 111 |
| 组间回归：+D、S | 50 / 110 |

（双向固定效应模型中，每个国家的残差按构造平均为 0，不能用来回答这个问题，所以改用组间回归。）

**判定**：**未触发**。中国在谜题图中是最大的异常值，但这主要是因为那张图没有任何控制变量。加入初始收入和投资率等常规增长要素后，中国落到前 15 名以外；再加入 S 后几乎没有残差。需要指出的是：**解释中国的主要是常规增长要素（高投资、低初始收入），而不是本研究新提出的 D、C、P**。

## 对研究计划的含义（供与导师讨论）

1. **核心机制 H2 在现有数据上不成立。** 下一步要么改进 C 的测量（特别是补上「政策试验/试点」一面，并在新数据上检验），要么接受「转化能力」这一构念在跨国面板上不可测、改走案例比较路线。后者也符合 Aizenman 讲义第 7.2 节的建议：用过程追踪补机制证据。
2. **最稳健的新发现是 H4（有条件）和深度的倒 U 形。** 二者可以统一为一个表述：**一体化的节奏与剂量比深度本身更重要**。这可能是论文更有前景的方向，但属于探索性发现，需要事前登记后再检验。
3. **数据局限**（详见各阶段小结）：GeoC/GeoV 未构造；PWT 人力资本是按其公式重算的；P 只覆盖 51 个发展中国家；Y1 只在投资/资本领域构造。
