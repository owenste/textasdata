# 模仿项目数据集编码手册（v0.1）

这一数据集是对第一轮大样本检验的重新设计。第一轮用国家—技术—年份面板检验模型一，失败原因有五个：分析层次不一致、时间窗口不对、只测到能力阶梯最底层、宽容度与外部监督分不开、约束软硬本身是结果。本数据集逐一对应处理。

| 第一轮的问题 | 本数据集的处理 |
|---|---|
| 分析层次不一致 | 分析单位改为**模仿项目**：一个可识别的组织在一个时期引进一项技术 |
| 时间窗口不对 | 结果在**项目开始后约 20 年**测量（项目提前终止的按终止时测量），落在引进后的关键期 |
| 只测到基础级 | 结果按**能力阶梯 0–3** 编码，区分基础级与中间级、高级 |
| 宽容度与外部监督分不开 | **外部观察者**单独编码，不并入宽容度或约束 |
| 约束软硬是结果 | 约束硬度只按**项目开始后前五年**的结构性安排编码，早于结果 |

## 变量

**宽容度**：沿用 `coding/latitude_codebook.md` 的三维度（fv 失败显现速度、fa 可归责程度、ps 性能标准明确程度），各 0–2 分，对被模仿的技术本身编码。

**约束硬度**：五个维度对应研究大纲的定义，每项 1 表示“硬”，0 表示“软”，只看项目开始后前五年。

| 变量 | 1（硬）的条件 |
|---|---|
| h_loss | 亏损不由上级补足（民间资本自负盈亏，或经费有明确上限、超支不补） |
| h_demand | 需求不受保障（没有指定采购、专营或进口禁令） |
| h_comp | 在其市场上面对竞争者（国内同行或进口产品） |
| h_cond | 支持或合同以绩效为条件（交付节点、出口目标、成本目标、国产化目标） |
| h_mgr | 负责人的去留与绩效挂钩（有因绩效撤换或向股东负责的记录） |

**约束依据（basis）**：functional（市场、出口、客户验收、可检验的交付）、administrative（行政考核或政治问责）、none（无）。

**外部观察者（ext）**：1 表示有国家保护管不到的外部观察者，且其判断会带来后果：出口市场、外国认证、国内市场上的外国竞争者、外国工程界对项目的公开检验。

**外部安全压力（press）**：项目开始时有明显的军事威胁或战争动员。

**能力层级（outcome）**，在 outcome_year 测量：

| 值 | 条件 |
|---|---|
| 0 仅完成引进 | 运行依赖外方人员，或建成后无法正常运转、被弃用 |
| 1 基础级 | 本国人员能常规运行与维护，但没有再造或改型 |
| 2 中间级 | 能自行复制生产线或装备、独立完成同类工程，或作出适应性改造 |
| 3 高级 | 自主设计的新产品或新工艺投入生产，或达到国际竞争水平 |

**置信度（conf）**：high / medium / low，反映二手文献对该项目编码依据的确定程度。

## 已知的局限

1. **单一编码者且知道结果。**编码者 A 在编码约束时已经知道各项目的结果，存在确认偏误的风险。缓解办法是约束只按可核查的结构性事实编码，并逐项写明依据；但第二编码者应在不看结果的情况下独立编码约束变量。
2. **依据来自二手文献与百科资料**，其中标注“待核”的来源需要查阅原始研究。
3. **项目选择不是随机抽样。**入选标准是二手文献充分，可能偏向知名的成功或失败案例。
4. **样本只有 30 个**，统计结果只能作为描述性证据。
