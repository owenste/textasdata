# 表 39 描述性分解：增长联动的南北来源（论文表 4；不在登记中）

主口径：南北弹性相同，南方占比 = 南方伙伴加权增长 / 全部伙伴加权增长，只要求 θ > 0，与 θ 的水平无关。
敏感性口径：用登记 L4 模型的估计弹性（θ_S = 0.5955，θ_N = 1.0395）分别加权；南北系数大小不作比较，只作敏感性参考。
